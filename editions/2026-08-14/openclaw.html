● What makes it different

Multi-channel messaging gateway

Connect to WhatsApp, Telegram, Slack, Discord, Signal, Google Chat, and iMessage simultaneously. Your AI is present wherever your team communicates.

Local-first architecture

The Gateway runs entirely on your hardware. Files, conversations, and model interactions never leave your device unless you choose to enable companion apps.

Flexible model support

Swap between hosted providers (OpenAI, Anthropic, Google) and local models seamlessly. No vendor lock-in by design.

ClawHub marketplace

An extensible plugin SDK and community marketplace of 100+ tools, skills, and integrations built by the community.

Multiple control interfaces

CLI for power users, TUI for terminal workflows, and a web-based Control UI dashboard for visual management and monitoring.

Security-first sandboxing

Configurable sandboxing and pairing verification ensure the agent operates within your defined boundaries and threat model.

Single best feature

One install, every platform you use

Instead of managing separate AI integrations for each messaging app, OpenClaw gives you a single self-hosted agent that appears natively across all your channels. Message it on WhatsApp from your phone, then pick up the same conversation on Slack from your desk - with full context continuity.

The problem it solves

AI assistants today lock you into one platform, one provider, and one set of privacy terms. OpenClaw breaks all three locks.

Before

Platform fragmentation. Using AI means switching between ChatGPT's web app, Claude's app, Gemini's interface - none of them talk to each other or integrate with your existing messaging workflow.

Cloud-only privacy. Every prompt, file, and conversation passes through third-party servers with opaque data handling policies.

Vendor lock-in. Switching AI providers means losing conversation history, custom instructions, and workflow integrations.

After

One agent, every channel. A single self-hosted instance serves all your messaging platforms simultaneously - WhatsApp, Slack, Telegram, Discord, and more.

Your hardware, your data. The Gateway runs locally. Files and conversations stay on your machine unless you explicitly choose otherwise.

Swap models freely. Switch between OpenAI, Anthropic, Google, or local models without losing your agent's context, skills, or integrations.

Set it up

Requires Node.js 22.22.3+ or 24.15+. Install in one command, then onboard and launch the dashboard.

1

Install

# macOS / Linux / WSL
curl -fsSL https://openclaw.ai/install.sh | bash

# Windows
iwr -useb https://openclaw.ai/install.ps1 | iex

# Or via npm
npm install -g openclaw@latest

The installer handles dependencies and configures base directories.

2

Onboard and launch

openclaw onboard --install-daemon
openclaw gateway status
openclaw dashboard

The onboard wizard walks you through model selection, messaging platform connections, and security configuration.

3

Connect a messaging channel

# Example: connect WhatsApp
openclaw channel add whatsapp

# Example: connect Slack
openclaw channel add slack --token xoxb-YOUR-TOKEN

Each channel connection is a one-command setup. The agent appears natively in each platform.

  • Security concerns documented. A Hacker News thread titled "OpenClaw is a security nightmare dressed up as a daydream" details prompt injection and data exfiltration risks through messaging platform integrations (Telegram link previews, vCards). HN thread

Watch out for

  • Messaging platform attack surface. Connecting to WhatsApp, Telegram, and others creates prompt injection vectors through link previews, vCards, and location pins. The security model is a real concern documented by researchers.
  • Star growth questions. Some Hacker News commenters have questioned the authenticity of the rapid star growth. Due diligence recommended.
  • Stability is a work in progress. A community thread captured frustration with stability issues during peak usage periods.
  • Non-profit governance. OpenClaw Foundation governance means slower feature velocity compared to VC-funded competitors.
