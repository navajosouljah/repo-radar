● What makes it different

Unified Rust core

GPU compositing runs on a platform-agnostic Rust engine. Web, desktop, and mobile share the same rendering pipeline.

Plugin-first architecture

First-class third-party plugin support via an Editor API. The editor is designed around extensibility, not as an afterthought.

MCP server for AI agents

AI coding agents can drive the editor via Model Context Protocol - automate edits, batch renders, and template generation.

Headless batch rendering

Process video projects without the UI. Script automated rendering pipelines for content at scale.

Built-in scripting tab

Write and run scripts directly in the editor interface - automate repetitive editing tasks without leaving the app.

No cloud, no watermarks

All processing is local. No subscription required, no watermarks on output, no files uploaded to third-party servers.

Single best feature

Video editing meets AI agents

The MCP server integration means AI agents can programmatically control the editor - inserting clips, applying effects, adjusting timing, and triggering renders. Combined with headless mode, this enables fully automated video production pipelines driven by AI.

The problem it solves

Video editing is locked behind proprietary apps with subscriptions, watermarks, and cloud dependencies.

Before

Proprietary lock-in. CapCut, Premiere, DaVinci - all proprietary with vendor lock-in, subscription fees, or cloud dependencies.

No extensibility. Want to add a custom effect or automate a workflow? You are limited to what the vendor provides.

Cloud-dependent processing. Many editors upload footage to cloud servers for processing, creating privacy and bandwidth concerns.

After

Open-source, free forever. MIT licensed. No subscription, no watermarks, no cloud uploads. Run it anywhere.

Plugin-first design. Build custom plugins via the Editor API. The extension ecosystem is a first-class feature.

Local processing only. All rendering happens on your hardware. Files never leave your device.

Set it up

Install the proto toolchain, then run the dev server for web, API, or desktop.

1

Install proto toolchain

# Linux / macOS / WSL
curl -fsSL https://moonrepo.dev/install/proto.sh | bash

# Windows
irm https://moonrepo.dev/install/proto.ps1 | iex

# From repo root
proto use

Proto manages the pinned tool versions needed for the project.

2

Run the dev server

# Web editor
moon run web:dev      # localhost:5173

# API server
moon run api:dev      # localhost:8787

# Desktop app
moon run desktop:dev

Each target runs independently. The web editor is the quickest way to start editing.

In the Wild

  • YouTube walkthrough. "OpenCut: The Free Open-Source Video Editor That Runs Everywhere" covers web, desktop, and mobile from a single codebase. YouTube
  • PrivacyTools.io review. Recommends OpenCut for quick social-video edits but suggests Kdenlive for deep effects or real color work. Calls it "young and rough in places." PrivacyTools.io
  • Filmora comparison review. "Open-Source CapCut Alternative? OpenCut Full Review" provides a thorough feature comparison against established editors. Filmora review

Watch out for

  • Young and rough. Multiple reviewers note missing features compared to mature desktop editors. Good for quick social-video edits, not for heavyweight VFX.
  • Active rewrite. The project is being rewritten from the ground up. Expect instability and breaking changes as the new architecture matures.
  • Hype may outpace features. The star count (45K to 83K rapid growth) suggests hype driven by the CapCut positioning is ahead of the current feature set.
  • Limited effects library. Compared to CapCut's extensive template and effect library, OpenCut's offerings are still minimal.
