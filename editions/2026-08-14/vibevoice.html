● What makes it different

60-minute single-pass ASR

Transcribes hour-long audio in a single forward pass - no chunking, no sliding windows. Speaker consistency and context are maintained throughout.

Multi-speaker TTS (up to 4)

Synthesizes conversations with up to 4 distinct speakers maintaining natural turn-taking. 90-minute generation maintaining semantic coherence.

7.5 Hz continuous tokenizers

Acoustic and Semantic speech tokenizers operate at an ultra-low frame rate, enabling efficient processing of very long audio without memory exhaustion.

Real-time streaming (0.5B model)

A lightweight 0.5B parameter model achieves approximately 300ms latency for real-time voice applications.

Structured transcription output

ASR output includes speaker ID, timestamps, and content in a structured Who/When/What format - not just raw text.

50+ languages natively

Multilingual by design. Experimental voices span 9 languages plus 11 English style variants.

Single best feature

Hour-long audio, single pass

Conventional ASR systems chunk audio into 30-second windows, losing global context and speaker consistency across boundaries. VibeVoice processes up to 60 minutes in a single forward pass, maintaining unified speaker tracking and semantic coherence throughout. For meetings, lectures, and podcasts, this is transformative.

The problem it solves

Voice AI models either work on short clips or require complex chunking pipelines. VibeVoice handles hours natively.

Before

Short-window ASR. Conventional systems chunk audio into 30-second windows, losing speaker context and semantic coherence across chunk boundaries.

Single-speaker TTS. Most TTS systems generate one voice at a time. Multi-speaker conversations require stitching separate generations together.

Closed-source dominance. The best voice AI models are proprietary - Whisper's successors, ElevenLabs, Play.ht - with usage fees and data upload requirements.

After

60-minute single pass. Process hour-long recordings without chunking. Speaker tracking and context are unified throughout.

Native multi-speaker synthesis. Generate 90-minute conversations with up to 4 distinct speakers, natural turn-taking, and sustained coherence.

Fully open-source. MIT license, Hugging Face integration, vLLM inference support. Run it on your own hardware.

Set it up

Available via Hugging Face Transformers and Azure AI Foundry Labs. Requires GPU for full-size models.

1

Install dependencies

pip install torch transformers soundfile

# For vLLM inference
pip install vllm

Standard PyTorch and Transformers stack. vLLM support for optimized inference.

2

Load and run TTS

# Load from Hugging Face
from transformers import AutoModel
model = AutoModel.from_pretrained("microsoft/VibeVoice-TTS")

# Generate speech
audio = model.generate(text="Hello world", speaker="en-US-1")

Standard Hugging Face Transformers API. Model-specific docs on the Hugging Face model card.

3

Run ASR transcription

# Load ASR model
from transformers import AutoModel
asr = AutoModel.from_pretrained("microsoft/VibeVoice-ASR")

# Transcribe (up to 60 minutes)
result = asr.transcribe("meeting.wav")

Single-pass transcription with structured Who/When/What output.

Watch out for

  • Research-only recommendation. Microsoft explicitly states VibeVoice is not recommended for commercial or real-world applications without further testing.
  • GPU required. Full-size models require substantial GPU resources. GitHub commenters note it is "overkill" for simpler use cases and unsuitable for lower-end hardware.
  • No commercial production readiness. Enterprise deployment is not yet established. Creative communities (Civitai) have adopted it, but production APIs are Azure-only.
  • Large model size. The full model is substantial and not suited for edge deployment or consumer hardware without significant optimization.
