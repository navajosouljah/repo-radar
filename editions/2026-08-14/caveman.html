● The compression stack

65% output compression

On average, agent responses are 65% shorter. The skill strips hedging, filler, and unnecessary explanation while preserving technical accuracy.

33% input compression via proxy

Caveman Proxy sits between the agent and the LLM, compressing tool schemas, logs, and context before they reach the model.

Seven native agent wraps

Claude Code, Gemini, Codex, Aider, opencode, Hermes, OpenClaw - wrap any of them with zero code changes.

Pixel mode

Renders dense text to PNG images for extreme compression scenarios - 79% token savings on long-line content like logs and tables.

Content-addressable recovery

CCR stores original bytes locally for exact recovery. Lossy compression is reversible on demand - nothing is truly thrown away.

Six intensity levels

From lite (removes hedging) to ultra (heavy abbreviation) to wenyan (classical Chinese patterns). Pick the aggression level that fits your workflow.

Single best feature

The readability win nobody expected

Users report the real value is not cost savings but speed. Caveman responses are faster to scan, quicker to act on, and cut through the filler that makes agent output exhausting to read. The token savings are a welcome side effect of what is fundamentally a readability upgrade.

The problem it solves

AI agents are pathologically verbose. Caveman makes them concise.

Before

Agents explain everything. Every response includes disclaimers, caveats, alternative approaches, and step-by-step reasoning you did not ask for.

Token costs scale with verbosity. Output tokens are expensive. Agents that say the same thing in 3x the words cost 3x the money.

Tool output bloat. Full tool schemas, complete logs, and entire file contents are sent to the model on every turn, wasting context window capacity.

After

Responses you can scan. Hedging, filler, and unnecessary explanation are stripped. What remains is technical accuracy in fewer words.

Lower cost per interaction. 65% fewer output tokens means meaningfully lower API costs on high-volume agent workflows.

Compressed input context. Proxy compresses tool results, logs, and schemas before they reach the model, freeing context window for actual work.

Set it up

Install the skill for quick output compression, or the full stack for input + output + pixel mode.

1

Skill install (simplest)

curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/v1.10.0/install.sh | bash

# Windows
irm https://raw.githubusercontent.com/JuliusBrussee/caveman/v1.10.0/install.ps1 | iex

Installs the output compression skill. No other dependencies needed.

2

Full stack install

npm install -g @caveman-ai/cli
caveman setup --install

# Wrap your agent
caveman claude
caveman gemini
caveman codex

Installs the CLI, proxy, and all seven agent wraps. Requires Node.js 18+.

  • Hacker News viral thread. 399 points, 238 comments. Author Julius Brussee participated in the discussion. A separate thread benchmarked Caveman against a simple "be brief" prompt. HN thread
  • The New Stack coverage. "Getting Claude Code to grunt in Caveman-speak might not save as many tokens as you think" - honest assessment of the gap between headline claims and measured performance. The New Stack

Watch out for

  • 65% is output only. The headline number applies to output tokens. Input and reasoning tokens are untouched. JetBrains measured 8.5% on real agentic tasks.
  • Skill overhead. The skill itself adds 1-1.5K input tokens per turn. On already-terse workloads, savings can go net-negative.
  • Dual license. MIT for skill/SDK/CLI; BSL-1.1 for engine/proxy/cache (converts to Apache-2.0 in 2030 or 4 years after each release). Commercial use of BSL components requires a license.
  • "Be brief" captures most value. HN skeptics note that a simple system prompt instruction like "be concise" captures most of the output compression without the overhead.
