● What makes it different

Built-in learning loop

The agent creates skills from interactions, improves them during use, and searches past conversations - the only agent with genuine self-improvement built into the core.

Dialectic user modeling

Honcho-powered user profiles build a persistent model of your preferences, communication style, and workflow patterns across sessions.

Multi-platform messaging

Telegram, Discord, Slack, WhatsApp, Signal, CLI, and email via a unified gateway - six integrations, one agent instance.

Infrastructure flexibility

Run on Docker, SSH, Singularity, Modal, Daytona, or Vercel Sandbox. Seven compute backends, from a $5 VPS to GPU clusters.

Full TUI with streaming

Multiline editing, slash-command autocomplete, conversation history, and streaming output in a polished terminal interface.

Built-in cron scheduler

Schedule unattended tasks - daily reports, weekly audits, recurring research - that run autonomously on your defined schedule.

Single best feature

Skills that compound over time

Ask Hermes to summarize a PR and it creates a skill for PR summarization. Next time, the skill fires faster and produces better output. Benchmarks show self-created skills cut research task time by 40% versus a fresh agent instance. The learning is domain-specific - it compounds where you use it most.

The problem it solves

Every AI agent starts from scratch every session. Hermes remembers, learns, and improves.

Before

Amnesia by design. Traditional AI agents forget everything when the session ends. Every new conversation starts from zero context.

Static capabilities. Agent skills are hardcoded by developers. The agent cannot learn new patterns from your specific workflow.

Vendor lock-in. Cloud-only agents tie you to one provider's pricing, data policies, and model selection.

After

Three-layer memory. Agent-curated memory, FTS5 session search, and dialectic user modeling keep persistent context across sessions.

Self-created skills. The agent observes patterns in your work and creates reusable skills that improve with use - no developer intervention needed.

Model-agnostic, self-hosted. Run on Nous Portal, OpenRouter, OpenAI, or custom endpoints. 300+ models, your infrastructure.

Set it up

One-command install on Linux, macOS, WSL2, and Termux. Auto-handles Python, Node.js, ripgrep, and ffmpeg.

1

Install

# Linux / macOS / WSL2 / Termux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc && hermes

# Windows
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

The installer handles all dependencies: uv, Python 3.11, Node.js, ripgrep, ffmpeg, and bundled Git Bash on Windows.

2

Connect to a model

# Use Nous Portal (their subscription)
hermes config set provider nous

# Or bring your own API key
hermes config set provider openrouter
hermes config set api-key YOUR_KEY

Supports Nous Portal, OpenRouter, OpenAI, Anthropic, and custom endpoints. 300+ models available.

3

Connect messaging channels

# Connect Telegram
hermes channel add telegram

# Connect Discord
hermes channel add discord --token YOUR_BOT_TOKEN

Six messaging integrations available. The agent appears natively in each platform.

Watch out for

  • Janky startup experience. Multiple testers report a slow, busy startup sequence and a CLI that can get in the way during rapid iteration.
  • Skill transfer is domain-specific. A skill learned from summarizing PRs does not transfer to database migration planning. Cross-domain generalization remains an open problem.

  • Token consumption. The learning loop and memory system consume additional tokens per session compared to stateless alternatives.
