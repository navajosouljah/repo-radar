● Architecture

Everything-is-a-plugin architecture

Models, tools, skills, sessions, sandboxes, filesystems, the agent loop, orchestration, and UI are all Cordis plugins. Nothing is hardcoded.

Spatiotemporal composability

Plugins can be composed across space (different components) and time (different stages of a workflow) via the Cordis meta-framework.

Browser-based UI

A web interface served locally at 127.0.0.1:3080 provides visual management of plugins, sessions, and agent state.

Open-source with MIT license

Fully open-source under MIT. DeepSeek's bet on community-driven development over proprietary lock-in.

Single best feature

The plugin boundary as API contract

By making everything a plugin - including the agent loop and the UI - DeepSeek Harness creates clear API contracts between every component. Want a different sandboxing strategy? Swap the sandbox plugin. Want a different model router? Replace the model plugin. The composability is structural, not bolted on.

The problem it solves

Agent frameworks are monolithic. DeepSeek Harness makes every piece replaceable.

Before

Monolithic agent frameworks. Adding or changing functionality in existing agent harnesses requires deep integration work and understanding framework internals.

All-or-nothing adoption. You either use the entire framework stack or build from scratch. No middle ground for selective component use.

Proprietary lock-in. The most capable agent platforms are closed-source, limiting customization and auditability.

After

Modular plugin composition. Every component is an independent plugin with clear interfaces. Mix and match as needed.

Selective adoption. Use just the agent loop plugin, just the sandbox plugin, or the full stack. Each piece works independently.

Fully open-source. MIT license, community-driven development, full source access for auditing and customization.

Set it up

One command via npx, or build from source. Requires Node.js.

1

Quick start via npx

npx @deepseek-ai/dsh web

Launches the web UI at 127.0.0.1:3080. The fastest path to running the harness.

2

Build from source

git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web

For contributors and developers who want to modify the framework or develop custom plugins.
