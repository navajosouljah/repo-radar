● What makes it different

Full layer compositing

Layers, folders, opacity, and every Photoshop blend mode. Layer masks and clipping masks for non-destructive editing. Adjustment layers for Hue/Saturation, Levels, Curves, Exposure, Gradient Map, and more.

Professional brush tools

Clone stamp, spot healing, liquify, and smear. The retouching tools you actually use in daily compositing work, without the 40 brushes you never open.

AI background removal

Built-in background removal using macOS Vision framework. No cloud upload, no API key. The model runs entirely on your Mac, keeping your images private and the workflow fast.

Real filters, not gimmicks

Gaussian blur, motion blur, lens correction, grain, and noise. The filters a compositor actually needs for professional post-processing and finishing work.

Selection tools

Marquee, lasso, and magic wand selections. Precise control over what you edit - the foundation of any serious compositing workflow.

Native Swift performance

Not Electron. Not a web wrapper. Pure Swift with Metal rendering. The app launches instantly, scrolls at 120fps on ProMotion displays, and uses a fraction of the memory Photoshop demands.

Install Compositor

Download the app or build from source. No account, no activation, no Creative Cloud.

1

Download the app

# Option A: Download from the website
open https://robbietilton.com/compositor

# Option B: Download from GitHub Releases
open https://github.com/robbietilton/Compositor/releases

Download the latest .dmg from either source. Drag Compositor to your Applications folder. That is it - no installer, no account creation, no activation key.

2

Build from source (optional)

# Clone the repository
git clone https://github.com/robbietilton/Compositor.git
cd Compositor

# Open in Xcode and build
open Compositor.xcodeproj

# Or build from the command line
xcodebuild -scheme Compositor -configuration Release

Requires Xcode 15+ and macOS 14 Sonoma or later. The project has no external dependencies - everything is built with Apple frameworks.

3

Start editing

# Open an image from the command line
open -a Compositor photo.png

# Supported formats: PNG, JPEG, TIFF, PSD, HEIC
# Compositor reads Photoshop layer files

Compositor opens standard image formats including PSD files with layers preserved. If you are migrating from Photoshop, your existing project files are a starting point, not a dead end.

Where Compositor fits

Compositor is not trying to replace every Adobe product. It replaces the Photoshop workflow for designers who composite, retouch, and post-process images.

Photo Post-Processing

Adjustment layers, curves, and color grading. Import your RAW exports from Lightroom or Capture One, then finish the work with layers, masks, and non-destructive adjustments. The workflow photographers actually do in Photoshop.

Design Compositing

Layer multiple images, mask edges, blend seamlessly. Product photography composites, social media graphics, marketing materials - the bread and butter of a designer's Photoshop usage. Compositor handles the layer stack, blend modes, and masking that make this work.

Quick Retouching

Clone stamp, spot healing, and liquify. Remove blemishes, fix backgrounds, clean up product shots. The retouching tools that get used daily, without waiting for Photoshop to launch and load its 200 plugins.

Open-Source Workflows

MIT-licensed, modify freely. Teams that cannot or will not pay Adobe subscriptions - open-source projects, non-profits, educational institutions, indie studios - get a professional compositing tool with no licensing anxiety.

Watch Out For

  • macOS only. Compositor is a native Swift app built with Apple frameworks. There is no Windows version, no Linux version, and no web version. If your team is cross-platform, this is a non-starter for shared workflows.
  • Nine days old. The repo was created September 16, 2026. This is extremely early-stage software. Expect missing features, rough edges, and bugs. Do not migrate your production workflow to it yet - test it alongside Photoshop first.
  • Solo developer. Compositor is built by one person. Bus factor is 1. If Robbie Tilton moves on, the project depends on whether a community forms around it. The MIT license helps here, but momentum matters.
  • Not a full Photoshop replacement. No text tool, no vector shapes, no 3D, no video timeline, no content-aware fill (beyond basic spot healing). If you need those features, Compositor is not the answer. It covers compositing, not everything Photoshop does.
