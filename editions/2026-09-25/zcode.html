Edition 009 · Week of September 25, 2026

DO NOT INSTALLzai-org/ZCode

ZCode

Z.ai's AI coding app. We ranked it #5 in Edition 009, then pulled it after our security review on September 27, 2026.

It was caught silently uploading users' entire code history to its maker's cloud.

1

What happened?

  • A developer's reverse-engineering report (September 18) found ZCode packing whole workspaces, including the full Git history, into encrypted archives and uploading them to Alibaba Cloud storage. Only Z.ai held the key to decrypt them.
  • In one examined install, a single upload was 313 MB covering 42,411 files, and 86.6% of it was the Git history.
  • It kept doing this with the two settings that looked relevant switched off.
  • Z.ai apologized, said it fixed the problem, and published the app's code on GitHub on September 21.
2

Why it still fails our check

  • The fix can't be verified. The published code can show what the app does now. It can't show what happened to code already uploaded to Z.ai's servers.
  • The repo can't be matched to the app people install. It launched as a 3-commit code drop from 2 contributors, with no development history.
  • The popularity isn't earned history. 6.9K stars in 7 days, on that same 3-commit history.
3

If you already used it

  1. Treat anything in the history of projects you opened with ZCode (API keys, tokens, passwords) as exposed, and change it.
  2. Uninstall it until an independent review confirms the app no longer uploads workspaces.
4
