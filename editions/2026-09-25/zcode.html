● What makes it different

Goal Mode

Set an objective and a token budget. ZCode runs the agent in repeated rounds - planning, executing, verifying - until the goal passes or the budget runs out. No babysitting required for multi-step refactors.

Three-surface monorepo

Desktop app, web client, and Agent CLI all live in one repo. Shared UI components and backend services mean the experience is consistent whether you work in Electron, a browser tab, or the terminal.

Deep GLM-5.2 integration

First-party model integration that no third-party editor can replicate. Z.ai's own model gets optimized prompting, tool routing, and latency tuning baked into the harness.

Remote task control

Kick off and monitor agent tasks from WeChat, Feishu, or Telegram. Start a long refactoring job from your phone and check back when it finishes.

Integrated workspace

File manager, terminal, Git panel, and browser preview sit alongside the agent chat. Everything in one window - no context switching between editor and terminal.

Free daily token budget

Z.ai's free tier provides 3 million GLM-5.2 tokens and 2 million GLM-5 Turbo tokens per day. Enough for serious agent work without a credit card.

Single best feature

Goal Mode turns coding into a fire-and-forget loop

Most coding agents run one turn at a time. You prompt, the agent acts, you review, you prompt again. Goal Mode changes the loop entirely. You describe the end state - "migrate all API routes from Express to Hono and make the test suite pass" - set a budget, and walk away. ZCode plans the work, executes in rounds, runs your tests after each pass, and stops only when the goal is verified or the budget is gone. For large mechanical refactors, this saves hours of back-and-forth supervision.

The fragmented workspace problem

AI coding tools keep multiplying, but most of them require you to stitch together an editor, a terminal, a model provider, and an agent harness separately. ZCode ships them as a single integrated package.

Before

Editor plus agent is a two-tool workflow. You run Claude Code or Codex in a terminal, then switch to VS Code to read the changes, then switch back to the terminal to continue. Context stays in your head.

Long tasks need constant supervision. A multi-file refactoring takes dozens of prompts. Each turn requires you to review output, decide the next step, and type the next instruction. You are the orchestrator.

Model lock-in or adapter tax. Want to try a different model? You need to swap API keys, adjust prompting strategies, and hope the harness supports the provider. Most do not make switching easy.

After

One window, full context. Files, terminal, Git, browser preview, and agent chat live side by side. Changes appear in real time as the agent writes them. No switching, no mental juggling.

Goal Mode handles orchestration. Define the outcome, set a budget, and let the agent loop through plan-execute-verify cycles on its own. You review the result, not each intermediate step.

First-party GLM support with provider flexibility. GLM-5.2 is optimized out of the box. Other providers work through configuration. The harness adapts its tool routing to the model in use.

Set up ZCode

Clone, install dependencies, and run the desktop app or CLI locally. Requires Git, Node.js 24.14.0 or later, and pnpm 10.33.2 or later.

1

Clone and install

# Clone the monorepo
git clone https://github.com/zai-org/ZCode.git
cd ZCode

# Install dependencies with pnpm
pnpm install

The repo includes the desktop app, web client, shared packages, backend services, and the Agent CLI. No submodule initialization needed - everything is a regular directory.

2

Run the Agent CLI

# The CLI lives in apps/zcode-cli/
cd apps/zcode-cli
pnpm dev

# Or build and run the desktop app
cd apps/desktop
pnpm build
pnpm start

The CLI gives you a terminal-based agent experience. The desktop app launches an Electron window with the full integrated workspace - file manager, terminal, Git, and agent chat.

3

Connect a model provider

# Default: Z.ai's GLM-5.2 (free tier available)
# Sign up at z.ai for an API key
export ZAI_API_KEY="your-api-key-here"

# Or connect third-party providers via settings
# Anthropic, OpenAI, and other providers supported

Z.ai's free tier gives you 3M GLM-5.2 tokens per day. For heavier workloads, paid plans are available. Third-party model providers can be configured through the settings panel.

Where ZCode fits

ZCode targets developers who want an integrated agent workspace rather than an agent bolted onto an existing editor.

Large refactors

Goal Mode shines on mechanical multi-file changes. Migrating a framework, renaming a domain concept across 200 files, or converting a codebase from CommonJS to ESM - set the goal, set the budget, let ZCode loop until the tests pass.

GLM-first teams

If your organization already uses GLM models, ZCode is the native IDE. First-party optimizations mean lower latency, better tool routing, and tighter integration than any third-party harness can offer for GLM-5.2.

Remote monitoring

Kick off agent tasks and monitor them from your phone. Start a refactoring job before lunch, check progress via Telegram or Feishu, and review the results when you get back. Useful for tasks that take 20 to 60 minutes of agent time.

Zero-cost prototyping

The free tier is generous enough for real prototyping. 3M tokens per day of GLM-5.2 means you can build and iterate on a side project without entering a credit card. Ideal for weekend experiments and hackathon projects.

In the Wild

  • VentureBeat launch coverage. VentureBeat covered ZCode's launch with "Z.ai launches ZCode to challenge Cursor, Claude Code and GitHub Copilot in AI coding," positioning it as a direct competitor in the agent IDE space. VentureBeat
  • Hacker News privacy controversy. A thread titled "ZCode, the GLM coding agent, silently uploads your Git history" reached the HN front page in September 2026. Researchers found ZCode was uploading entire .git directories - including reflogs, deleted branches, and LFS assets - to Aliyun cloud storage. Z.ai apologized and attributed it to a repo-indexing feature enabled by default. Hacker News
  • The Register follow-up. The Register ran a piece titled "Z.ai says sorry for slurping up your code, open sources ZCode," covering the company's decision to open-source the full codebase as a response to the trust fallout. The Register
  • YouTube reviews. Multiple YouTubers published reviews comparing ZCode to Cursor and Claude Code. Bitdoze's detailed review covers Goal Mode, the free tier, and a direct feature comparison. Bitdoze
  • DEV Community write-ups. Several posts on dev.to dissect the Git-upload incident in detail, including a forensic analysis showing one snapshot reached 313 MB and 42,411 files with 86.6% being the .git directory. DEV Community

Watch out for

  • The Git-upload incident is recent and real. ZCode was caught silently uploading entire Git histories - including .git directories, reflogs, and LFS assets - to Aliyun Object Storage. The encryption keys were held solely by Z.ai's servers. The behavior has been attributed to a now-disabled default feature, but the trust damage is fresh. Audit your network traffic if you use ZCode on sensitive repos.
  • Five days old as open source. The repo was created on September 20, 2026. The codebase was proprietary before that. Community governance, contribution norms, and code review practices are still forming. Treat it as early-stage open source.
  • GLM-5.2 dependency. ZCode is optimized for Z.ai's own model. If you use a third-party provider, some features - like Goal Mode's verification loop - may not work as smoothly. The first-party integration is the selling point and the lock-in risk.
  • Hacker News flagged UI similarity to Codex. Multiple commenters noted that ZCode's interface closely resembles OpenAI's Codex UI. Whether this is convergent design or something else, it is worth noting if originality matters to you.
