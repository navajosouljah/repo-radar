Human-Agent-Society/reef

Teach your agents to keep getting better. Reef is the first open-source infrastructure that connects agent inference, feedback, learning, and versioned delivery into a single loop. ● What makes it different

Serve-Observe-Grow-Commit cycle

Reef processes learning in four distinct stages. Serve handles inference via an OpenAI-compatible endpoint. Observe matches feedback to recorded interactions. Grow trains a candidate update. Commit evaluates and publishes the winner.

Two learning surfaces

You can improve model weights using Slime and SGLang, or improve the agent harness - its prompts, rules, and skills. Most agent frameworks only let you do one. Reef supports both in the same pipeline.

Versioned delivery with rollback

Reef versions every model and harness artifact. A candidate update that fails evaluation is rejected automatically and the serving version stays unchanged. Think git for your agent's brain.

Feedback-native inference server

The inference endpoint returns an x-reef-agent-record-id header. Applications attach rewards, evaluator scores, or user corrections to that record. No separate logging pipeline needed.

OpenAI-format compatibility

Reef exposes a standard OpenAI-format endpoint for inference. Drop it in front of any agent framework that speaks the OpenAI API. No custom client libraries or protocol changes required.

Reefine tutorial included

The repo ships with Reefine, a guided tutorial that walks through the full path from requesting a harness change to installation. Run it against a local Ollama model to see the entire cycle end to end.

Single best feature

Learning baked into the inference server itself

The core insight behind Reef is that an inference server should collect learning material instead of discarding each interaction after returning an answer. Every request flowing through Reef is a potential training example. Attach a reward signal - a test passing, a user thumbs-up, a rubric score - and Reef uses it to produce a candidate improvement. This happens inside the serving infrastructure, not in a separate offline pipeline you have to build and maintain. The result is an agent that genuinely improves from use, with versioned checkpoints so you can always roll back.

The stagnant agent problem

Your agent accumulates valuable feedback every day - test results, user corrections, rubric scores - but none of it makes the agent smarter. Turning that signal into improvement requires a painful offline pipeline.

Before

Feedback goes nowhere. Your agent fails a test, a user corrects it, a rubric scores it low. All of that signal is logged somewhere and forgotten. The agent makes the same mistakes tomorrow.

Improvement requires a separate pipeline. To actually make your agent better, you have to export logs, build datasets, retrain, evaluate, and redeploy. This is a multi-week engineering project - so it almost never happens.

No safe rollback. When you do manage to ship an improved model or harness, there is no versioning. If the new version is worse on some tasks, you are stuck with manual debugging and ad-hoc rollbacks.

After

Feedback drives improvement automatically. Every interaction through Reef can receive a reward or correction. The system matches feedback to the original request and queues it for the learning pipeline. No export step, no dataset curation.

Learning is part of serving. Reef integrates the entire cycle - inference, feedback collection, candidate training, evaluation, and versioned deployment - into a single infrastructure layer. The offline pipeline disappears.

Safe, versioned delivery. Every candidate update is evaluated against the current version on your tasks. The winner gets published. Losers are rejected automatically, and the serving version stays stable. Roll back to any checkpoint.

Set up Reef

Get the continual learning loop running locally in a few minutes. Reef connects to SGLang or Ollama for inference and uses its own pipeline for the learning cycle.

1

Clone and install

git clone https://github.com/Human-Agent-Society/reef.git
cd reef

# Install dependencies (Python 3.10+)
pip install -e .

Reef is a Python package. Install it in a virtual environment or use the provided Docker setup for a fully isolated deployment. The repo includes configuration templates for common setups.

2

Start the inference server

# Start Reef with a local model via Ollama
reef serve --model ollama/gemma4:26b

# Or connect to an SGLang-served model
reef serve --model sglang/your-model --sglang-url http://localhost:30000

Reef exposes an OpenAI-compatible endpoint that your agent framework connects to. Requests flow through Reef's recording layer, which captures each interaction for the learning pipeline.

3

Run the Reefine tutorial

# Walk through the full harness-improvement cycle
reef serve --recipe reefine --model ollama/gemma4:26b

# This walks you through:
# 1. Sending requests and recording interactions
# 2. Attaching feedback (rewards, corrections)
# 3. Training a candidate harness update
# 4. Evaluating and committing the improvement

The Reefine tutorial shows the complete path from feedback to improvement. You will see a harness change proposed, evaluated against the current version, and published as a new release if it wins.

Where Reef fits

Any agent that runs repeatedly on similar tasks benefits from continual improvement. Reef handles the infrastructure so you can focus on the agent itself.

Coding Agents

A coding agent that learns from test results. Every time your coding agent's output passes or fails tests, that signal feeds back into Reef. Over time, the agent learns your project's patterns - which libraries to use, how to structure tests, what error handling your codebase expects. The harness surface lets Reef improve prompts and rules without retraining the model.

Customer Support

Support bots that improve from human corrections. When a support agent gives a wrong answer and a human corrects it, Reef captures that correction as a feedback signal. The next candidate update incorporates the fix. Over weeks, the agent's accuracy on your domain improves continuously.

Research Assistants

Lab assistants that refine their methodology. Research agents that search literature, summarize findings, or draft analyses can improve from rubric-based evaluation. Score each output, let Reef train a candidate, and the assistant learns what quality means in your domain.

Internal Tools

Enterprise agents that adapt to your workflows. Internal agents for document processing, data extraction, or workflow automation accumulate domain-specific feedback. Reef turns this into incremental improvement without requiring your ML team to build and maintain a training pipeline.

Watch out for

  • Very young project. Reef was created on August 31, 2026 - less than a month old. The API surface, configuration format, and pipeline architecture may change significantly. Pin your version and watch the releases closely.
  • Feedback quality matters. Reef can only learn from the signal you provide. Noisy rewards, inconsistent rubrics, or sparse corrections will produce mediocre candidates. Invest in your feedback pipeline as much as in Reef itself.
  • Evaluation is your responsibility. While Reef automates candidate evaluation, you define what "better" means. Poorly designed eval tasks will approve bad candidates or reject good ones. Design your evaluation suite carefully.
  • Compute requirements for model-weight learning. Harness improvements (prompts, rules, skills) are lightweight, but training model weights via Slime and SGLang requires GPU resources. The harness surface is the easier starting point for most teams.
