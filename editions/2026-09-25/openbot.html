OpenBot

A control room you run yourself, where each AI helper gets its own locked-down computer instead of the run of your machine.

Give one of its AI coworkers a job, and your own rules approve every click and file it touches before it happens, on its own sealed-off computer, with a plain record of what it did and why.

How does it work?

Your problem

Turning an AI helper loose on your browser and files is risky: one wrong click can hit the wrong website or the wrong file, and afterward it's hard to say exactly what it did.

Most AI agent setups run right inside your own browser and file system, so a mistake there is a mistake on your real machine.

When it kicks in

You start a conversation with one of your coworkers in its own channel, or a schedule starts it for you.

Message it directly, or set it on a repeating schedule and it starts itself in that same channel at the time you picked.

You give it

A plain-language job, plus whichever tools you already decided that coworker may use.

For example: a browser limited to your own company's sites, files it may read but not change, or a connection to Google Drive or Notion. Any agent that speaks AG-UI (an open standard for how an agent talks to its interface) can fill the coworker role, whatever framework built it.

It does

It plans its next move and checks with your rules before doing anything.

  1. It decides what it wants to do next - open a page, click something, read or save a file
  2. That plan goes to one gatekeeper first, which compares it against the rules you wrote
  3. An allowed action runs on that coworker's own computer, its own browser and files, never yours, and gets written to a record before it happens
  4. If it hits a login wall or a two-factor prompt, it stops and asks a person to take over

Try it yourself: ask a coworker to open news.ycombinator.com and tell you the top story, then read the record of exactly what it did.

You get

Work you can watch happen, and a record of exactly what happened.

  • Work carried out where you can watch itA live view of the coworker's own screen while it works, in its channel
  • A complete, readable record of every actionA list of what was allowed, what was refused, and which rule caused it
  • A coworker you can safely hand real logins toIts browser, files and tool access all stay inside its own locked-down computer, not yours

What changes for me?

Without it

  • Most AI agent setups run right inside your own browser and files, so one bad action is a mistake on your real machine.
  • It's hard to know exactly what an agent did after the fact, or to stop it before it does something you'd have refused.
  • Picking one agent framework to build on usually locks you into it.

With it

  • Each coworker gets its own computer: its own browser, its own files, only the tools you specifically allow.
  • Every action is checked against your rules before it happens, and written to a record you can read afterward.
  • Any agent that speaks the same open connection standard can be a coworker here, so switching frameworks doesn't mean starting over.

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. A developer clones the repository, copies .env.example to .env, and follows the README's Quick start to connect a free CopilotKit Intelligence project and add a model key.
  2. Run bash scripts/start.sh to bring up the database, the API and the app, then watch the demo video to see what a working setup looks like.
  3. In your running copy, message a coworker to check a page online and report back, then read /admin/audit to see exactly what it did and why it was allowed.

What it takes on your computer

Space on disk
About 1.4 GB for the container image itself (the app, the API and one coworker's browser together), per OpenBot's own measurement. Its docs recommend 4 GB free minimum, 8 GB so a coworker has room to save files.
Memory while it runs
409 MB just idling, growing to about 550 MB with one coworker's browser active (OpenBot's own measurement, on an Apple-chip machine). Its docs recommend at least 2 GB, 4 GB if several coworkers work at once.
Runs on
Mac, Windows or Linux with Docker (a tool for packaging software to run the same way anywhere) installed. Also needs Bun 1.3+ to build the app, a PostgreSQL database (or let OpenBot run one for you), a model API key (OpenAI, Anthropic or others - none is bundled), and a CopilotKit Intelligence project (a free plan exists, and it can be run on your own server too).
Source: OpenBot docs: Deployment - Minimum size, and README Requirements

Should I?

Great if you...

  • You have a developer who can run Docker (a tool for packaging software to run the same way anywhere) and wants AI agents that can touch real tools without touching your production systems
  • You need to show your boss or an auditor exactly what an AI agent did and why it was allowed to

Skip it if...

  • You want something to sign up for today - this is a template you run and maintain yourself, not a hosted product
  • You're not comfortable running a database and a model API key (a code the AI provider issues you) yourself - there's real setup here

Instead, you could look at

  • Grok Bot (xAI)The closed, hosted product OpenBot's own launch post positioned itself against - AI teammates you subscribe to (through a SuperGrok or Cursor plan) rather than run and govern yourself.

Is it safe?

PASSED

  • Searches for CVEs, vulnerabilities, malware and scams20 results read, including the national CVE database: nothing found
  • Are the stars earned?5.6K stars, 31 contributors, 431 commits. No data found - findarepo does not track this repo.

Watch out for

  • A template, not a hosted product. Nothing to sign up for - you clone it, configure it, and run and maintain it yourself.
  • Alpha, and it needs more than its own free code. It also needs a CopilotKit Intelligence project (a free plan exists, and you can run that part yourself too) for memory and lasting conversations - it isn't fully stand-alone yet.
  • 41 days old and moving fast. 15 releases already, at v0.0.15 - expect breaking changes between versions.
  • We found no independent report yet of a team actually running this day to day. The coverage so far is about the launch, not about results.
