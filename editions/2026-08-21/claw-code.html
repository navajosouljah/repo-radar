● What makes it different

Clean-room Claude Code architecture

Reimplements Claude Code's agent architecture - codebase reading, edit planning, command execution - without using Anthropic's proprietary code. Works with any LLM provider, not just Claude.

Multi-provider by design

Swap between OpenAI, Anthropic, Google, and local models freely. The original Claude Code locks you to Anthropic's API - claw-code does not.

Rust core, Python extensions

Performance-critical agent loop written in Rust, with Python used for plugin extensibility. The Rust port is still maturing but functional.

Agent-managed development

Self-described as an "agent-managed museum exhibit" - portions of the codebase are written and maintained by AI agents (Gajae-Code, LazyCodex) as a demonstration of agentic development.

Benchmarked against the original

A Towards AI article tested claw-code on 15 coding tasks and reported it matched or beat Claude Code on 9 of 15 - though the benchmark methodology was informal.

Explosive growth with caveats

Fastest repo to 100K stars, but the authenticity of the star count is widely debated. One developer estimated 95% of people who starred never cloned it.

Single best feature

Claude Code's architecture, any model

The core value proposition is provider freedom. If you like how Claude Code works but want to run it against GPT, Gemini, or a local model, claw-code is the closest open-source option. The architecture mirrors the original's codebase reading, edit planning, and command execution pipeline.

The problem it solves

Claude Code is one of the best terminal coding agents - but it only works with Anthropic's API and its source code is proprietary. Claw-code breaks both constraints.

Before

Vendor lock-in. Claude Code requires an Anthropic API key. Want to use the same workflow with GPT or Gemini? Start over with a different tool.

Closed source. You cannot audit, modify, or self-host Claude Code's agent logic. Enterprise teams with compliance requirements hit a wall.

No open reference architecture. The design patterns that make Claude Code effective were not documented or available for the community to learn from.

After

Any provider. Point claw-code at OpenAI, Anthropic, Google, or a local model. Same agent loop, your choice of brain.

Fully open source. MIT-licensed Rust and Python. Read the architecture, fork it, modify it, self-host it.

Documented patterns. The clean-room rewrite makes Claude Code's architectural patterns visible and learnable for the open-source community.

Set it up

Clone the exhibit and run it locally, or fork it to test your own agent against the same Rust codebase.

1

Clone and build

# Clone the repo
git clone https://github.com/ultraworkers/claw-code.git
cd claw-code

# Build with Rust (requires rustup)
cargo build --release

Requires Rust 1.80+ and a standard toolchain. The codebase is pure Rust with no external C dependencies.

2

Run the exhibit

# Run the compiled binary
cargo run --release

# Or run tests to validate agent output
cargo test

The test suite is the primary way to verify agent code quality. All tests were also written by the agents.

3

Fork and benchmark your agent

# Fork on GitHub, then point your agent at it
# Compare your agent's output against the original commits
git log --oneline --author="gajae-code"
git log --oneline --author="lazycodex"

The commit history shows exactly what each agent contributed. Use it as a comparison baseline for your own agent's approach.

Real-world use

How the community is using claw-code as a reference point for agent-driven development.

109K forks

Fork-as-benchmark. The extraordinary fork count suggests developers are using claw-code as a standardized challenge - fork the repo, point your own agent at it, and compare results against the original agent-written code.

Rust + agents

Type-safety stress test. Developers reference claw-code when debating whether AI agents can handle strict type systems. The repo is cited as evidence that agents can navigate Rust's borrow checker - with caveats.

Dual-agent
patterns

Multi-agent coordination research. The Gajae-Code/LazyCodex split is studied by teams building their own multi-agent workflows - how to divide architecture from implementation.

In the Wild

  • Hacker News launch threads. Multiple HN threads covered the initial rewrite, including discussions of the architecture and its relationship to Claude Code. HN: Claw Code rewrite and HN: Architecture explained
  • Independent benchmarks. A Towards AI author tested claw-code against Claude Code on 15 coding tasks and reported it matched or beat the original on 9 of 15. Towards AI benchmark
  • DEV Community hands-on. A dev.to author tested the repo and confirmed it reads codebases, plans edits, and runs commands across any LLM backend. DEV: What Claw Code actually does
  • Star authenticity questioned. Developer Volodymyr Stoiko publicly stated: "Repositories like ultraworkers/claw-code just prove how useless the stars metric has become. 140k in one day. My guess is 95% of people who starred or forked it didn't even clone it." Source
  • Copyright controversy. An open issue on the Anthropic claude-code repo titled "[COPYRIGHT] Take down this stupid repo" debates whether the clean-room claim holds up. GitHub issue

Watch out for

  • Star inflation. Carnegie Mellon researchers have documented millions of suspected fake/coordinated stars on GitHub. Claw-code's explosive growth pattern is a frequent example cited in these discussions.
  • Not production-ready. Multiple sources (WaveSpeed, Eigent.ai) explicitly advise against production use. It lacks Claude Code's permission system, enterprise features, and the Rust port is described as unstable.
  • IP and legal risk. Born from a source map leak, the "clean-room" rewrite claim is disputed. Anthropic has not taken legal action, but the origin story creates uncertainty for enterprise adopters.
  • Repo locked during transition. The repository has been locked during an ownership transfer. The claw-code crate on crates.io is a deprecated stub that prints "claw-code has been renamed to agent-code."
