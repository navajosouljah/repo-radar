● What makes it different

Not a framework - just files

No dependencies, no build step, no SDK. Each persona is a standalone markdown file you copy into your agent's config directory. Works with Claude Code, Cursor, Codex, Copilot, Aider, and more.

12 divisions, every function

Organized like a real agency: engineering, marketing, sales, security, design, data, DevOps, QA, product, legal, HR, and community management. Each division has multiple specialist roles.

Companion native app

The agency-agents-app companion provides visual browsing and one-click persona installation. No more hunting through directories - browse, preview, and install from a GUI.

Nexus Spatial Discovery

Multi-agent coordination exercises that let persona teams work together. Designed for workflows where a frontend specialist hands off to a backend architect, who hands off to a security reviewer.

Domain-narrowed expertise

Each persona carries specific domain knowledge, constraints, and best practices. A security reviewer persona knows OWASP, a React specialist knows hooks patterns - they stay in their lane.

Community-driven growth

Started with roughly 140 personas, now past 200 and growing. The community contributes new specialists as new agent use cases emerge across industries.

Core value proposition

Turn any generalist agent into a specialist

The pitch is simple: your AI coding agent gives the same generic responses regardless of the task. Drop in a persona file and it becomes a domain expert - a React performance optimizer, a Kubernetes security auditor, or a Reddit community strategist. Each persona is a curated system prompt that narrows the agent's focus and reduces hallucinations by keeping it in its lane.

The problem it solves

AI coding agents are powerful generalists - but generalists hallucinate more, miss domain nuances, and give boilerplate answers. Agency-agents narrows each agent to a specific expert role.

Before

Generic behavior. Your AI agent gives the same style of response whether you ask about React performance, Kubernetes security, or marketing copy. It is a jack of all trades, master of none.

More hallucinations. Without domain constraints, generalist agents confidently suggest outdated patterns, misapply best practices, or invent APIs that do not exist.

No organizational structure. When you need multiple specialists on a project, there is no predefined way to coordinate handoffs between a frontend agent, a backend agent, and a security reviewer.

After

Domain-narrowed focus. Each persona constrains the agent to a specific domain. A React specialist knows hooks, a security reviewer knows OWASP - they stay in their lane and hallucinate less.

Expert-level prompting. Each 300-500 line persona encodes domain best practices, constraints, and vocabulary that would take hours to write from scratch.

Agency structure. Twelve divisions mirror a real organization. Nexus exercises coordinate multi-agent handoffs so specialists collaborate instead of duplicating work.

Set it up

Three paths to get started - clone the repo, copy individual personas, or use the companion app for a visual experience.

1

Clone or download the repo

# Clone the full persona library
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents

# Browse the divisions
ls divisions/

The repo is organized by division. Each directory contains the specialist personas for that business function as standalone markdown files.

2

Copy personas to your agent's config

# For Claude Code
cp personas/react-specialist.md .claude/skills/

# For Cursor
cp personas/react-specialist.md .cursor/rules/

# For other agents - check their config directory

Each agent tool has its own config directory. Copy the persona markdown file there, and the agent loads it automatically on every session.

3

Or use the companion app

# The agency-agents-app provides a visual browser
# Browse, preview, and one-click install personas
# See: github.com/msitarzewski/agency-agents-app

The companion native app lets you visually browse all 200+ personas, preview their contents, and install them to your agent's config directory with a single click.

Watch out for

  • Prompt engineering vs real agency. Critics argue these are just elaborate system prompts, not genuine autonomous agents. Curated persona files are a convenience layer, not a paradigm shift in how agents work.
  • Context overhead. Each persona is 300-500 lines that loads with every API call. Most of those lines are irrelevant to your specific task - you are paying tokens for breadth you may never use.
  • No HN traction. Surprisingly zero prominent Hacker News discussion for a repo with 147K stars. The absence of organic technical discourse is notable for a project of this size.
  • Deep usage testimony is thin. Massive star count, extensive introductory blog coverage, but few "I used this for three months and here is what happened" retrospectives. The most substantive user perspective was someone who chose not to use it at all.
