● What made it stand out

1M token context window

The largest context window of any terminal AI agent. Entire codebases fit in a single session - no chunking, no retrieval tricks, just raw context.

Built-in Google Search grounding

Real-time web search integrated into the agent loop. Ask about documentation, check API changes, or verify facts without leaving the terminal.

Interactive PTY shell support

Handles interactive programs like vim, htop, and input prompts natively. Most competing agents choke on anything that expects a TTY.

Plan Mode (read-only default)

Since v0.34.0, Gemini CLI starts in Plan Mode by default - read-only exploration before any file changes. Safer by design.

Conductor extension

A structured spec-driven development workflow. Define specifications, let the agent implement them step by step. Closer to engineering than prompting.

GitHub Actions integration

Autonomous bug fixing in CI. Connect Gemini CLI to your GitHub Actions workflow and let it triage, diagnose, and fix issues on push.

What was the best feature

Completely free, no credit card required

1,000 requests per day on the free/personal tier. No API key purchase, no billing setup, just a Google account. For students, hobbyists, and budget-conscious developers, nothing else came close. That tier ended June 18, 2026 - Google is transitioning users to the closed-source Antigravity CLI.

The problem it solved

Terminal AI agents cost money per API call. Gemini CLI eliminated that barrier entirely - then took it away.

Before

Pay-to-play terminal agents. Claude Code, Cursor, and other AI coding tools required API keys or subscriptions. Every request cost real money.

Students priced out. The most powerful coding agents were inaccessible to anyone without a budget for API calls. Free tiers were stingy or nonexistent.

Small context windows. Most agents could only hold a few files in context at once, requiring complex retrieval strategies for larger codebases.

After (and then after that)

Completely free access. Gemini CLI offered 1,000 requests/day with no credit card. The largest free tier any terminal agent has offered.

1M tokens of context. Entire codebases fit in one session. No chunking, no RAG pipelines, just load and work.

Then Google deprecated it. The "killedbygoogle" pattern struck again. Free/personal tier ended June 18, 2026. The open-source Apache 2.0 client is being replaced by closed-source Antigravity CLI. Many developers have already migrated to Claude Code or Codex.

Set it up

Installation is straightforward, but note: the free tier ended June 18, 2026. Enterprise users with Gemini Code Assist licenses retain access.

1

Install Gemini CLI

# Install via npm
npm install -g @anthropic-ai/gemini-cli

# Or via Homebrew
brew install gemini-cli

Requires Node.js 18+ for the npm install path.

2

Authenticate with Google

# Authenticate with your Google account
gemini auth

Opens a browser window for Google OAuth. Enterprise users authenticate through their Gemini Code Assist license. Personal/free accounts no longer have access as of June 18, 2026.

3

Run in any project directory

# Navigate to your project and start the agent
cd your-project
gemini

Gemini CLI reads your project structure and enters Plan Mode (read-only) by default. Approve changes explicitly before any files are modified.

Real-world use

How developers used Gemini CLI before the deprecation - and why many have moved on.

1M tokens

Large codebase exploration. The 1M token context window was the killer feature for navigating massive codebases. Load an entire monorepo, ask architectural questions, trace call chains across hundreds of files - no retrieval pipeline needed.

$0/day

Budget-conscious development. Students and hobbyists used Gemini CLI as their primary coding agent because it was genuinely free. No credit card, no metered billing, no surprise invoices. Now requires an enterprise Gemini Code Assist license.

Gemini +
Claude

Hybrid workflow. Many developers used Gemini CLI for initial exploration and understanding (leveraging the large context window), then switched to Claude Code for precision edits and implementation. Different tools for different phases.

CI/CD

GitHub Actions autonomous bug fixing. Connect Gemini CLI to your CI pipeline. On test failure, the agent reads the error, traces the issue, proposes a fix, and opens a PR - all without human intervention.

In the Wild

  • HN launch - free tier excitement. The original launch thread was dominated by excitement about the free tier and 1M token context. Developers compared it favorably to paid alternatives. HN: Gemini CLI launch
  • Deprecation backlash. "Gemini CLI will stop working from June 18, 2026" - dominant sentiment was resignation and "killedbygoogle" jokes. Little surprise, much disappointment. HN: Deprecation thread
  • Open source bait-and-switch. "Gemini CLI was open source. Antigravity CLI is not." - the community viewed the transition from Apache 2.0 to closed-source as a bait-and-switch that eroded trust. HN: Open source loss
  • Token efficiency benchmarks. DataCamp tested identical tasks: Gemini consumed 432K input tokens vs Claude Code's 261K. 65% more tokens for the same work. DataCamp: Gemini CLI vs Claude Code
  • CVSS 10.0 critical vulnerability. A critical OS command injection bug was found in the container launcher - the maximum severity score. Patched, but a reminder of the security stakes in terminal agents. Hacker News: CVSS 10.0 RCE
  • Official deprecation announcement. Google's developer blog post formally announcing the transition from Gemini CLI to Antigravity CLI. Google: Transition announcement

Watch out for

  • Free tier is dead. Personal/free users lost access June 18, 2026. Only enterprise Gemini Code Assist licensees retain access. If you are evaluating Gemini CLI for personal use, it is no longer an option.
  • Closed-source successor. Antigravity CLI is closed-source and Go-based. The open-source Apache 2.0 promise is gone. Developers who chose Gemini CLI for its openness have lost that guarantee.
  • Token inefficiency. DataCamp benchmarks show Gemini uses 65% more input tokens than Claude Code on identical tasks (432K vs 261K). More tokens means slower responses and, for enterprise users, higher costs.
  • CVSS 10.0 vulnerability. A critical OS command injection bug was found in the container launcher - the maximum possible severity score. It has been patched, but terminal agents with shell access carry inherent security risk.
  • "Killedbygoogle" trust deficit. Many developers have migrated to Claude Code or Codex rather than adopt Antigravity. Google's track record of sunsetting products makes long-term commitment risky.
