How does it work?

Your problem

Your AI agent can write code and build websites, but it cannot make a video.

To get a product demo, someone still has to open a screen recorder or an editor like Premiere.

You give it

You give it an HTML page with animations - the same code your agent already writes.

An HTML page with a GSAP animation showing a dashboard filling in, or a Lottie icon spinning.

It does

It opens the page in a hidden browser, plays every animation frame by frame, and records each one.

Headless Chrome renders each frame, FFmpeg stitches them into a video at the frame rate you set.

You get

You get a finished MP4 that looks exactly like the page, with smooth animations at any resolution.

A 1080p demo video of your product, made from code, with no manual editing.

What changes for me?

Without it

  • Making a product video means opening screen-recording software or hiring an editor.
  • AI coding agents can build apps and websites, but they stop at "here's a screenshot".
  • Automated video tools often stutter or miss animations because they capture in real time.

With it

  • Your AI agent writes an HTML page, runs one command, and gets a finished MP4 back.
  • Frame-by-frame capture means every animation plays perfectly, even complex ones with GSAP or Three.js.
  • The same page renders at any resolution - 1080p, 4K, vertical for phone - without re-editing.

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Run `npx hyperframes init my-video` to scaffold a starter project.
  2. Run `npx hyperframes preview` inside the folder to see a live preview with hot reload.
  3. Run `npx hyperframes render` to produce a finished MP4 from your HTML.

Paste this into Claude Code. It runs your safety scan first, then a 10-minute test.

/skillspector https://github.com/heygen-com/hyperframes

If that scan passes: run `npx hyperframes init my-video`, then `cd my-video && npx hyperframes preview` to see the live preview, then `npx hyperframes render` to produce the MP4. 10 minutes max.

Should I?

Great if you...

  • You build AI agents or tools that need to produce video output automatically
  • You want pixel-perfect recordings of web animations without screen capture

Skip it if...

  • You want to edit videos by hand - this is for automated, code-driven production
  • You need talking-head or camera-based video, not animated web content
  • You are not a developer: there is no visual interface

Instead, you could look at

  • RemotionReact-based video creation: write React components and render them to video. More mature but React-only, and freemium (free for teams of 3 or fewer).
  • RevideoMIT-licensed library for batch video generation from code. Community fork of Motion Canvas.

Is it safe?

PASSED
  • Security advisories: 0GitHub's advisory list, checked Sep 27
  • Searches for CVEs, vulnerabilities, malware and scams0 results read, nothing found
  • Are the stars earned?53.5K stars, 72 contributors, 4.8K commits

Watch out for

  • Developer-only tool. There is no visual interface: you write HTML and run a command. This is for developers and AI agents, not for someone who wants to drag and drop.
  • Pre-1.0 with rapid churn. 400+ releases in 5 months, currently v0.8.80. The API may change, and users report the AI gets you about 80% of the way - human polish is still needed.
  • Made by HeyGen. HeyGen is a well-funded video AI company. HyperFrames is open-source (Apache 2.0), but HeyGen's core product is paid and cloud rendering ties into their platform.
