★ Single best feature

The org chart + heartbeat control plane

Paperclip coordinates multi-agent workflows the way a company coordinates people: reporting lines, atomic task checkouts, and scheduled heartbeats. It eliminates multi-terminal chaos, prevents runaway token spend through hard budget caps, and keeps agents working around the clock.

▦Org charts & reporting lines

Structure agents into teams with managers and reports, so work flows down and status flows up - like an actual company.

◔Token budget caps

Hard monthly budget caps per agent halt overspend automatically before a runaway loop burns your bill.

✓Atomic task checkouts

Tasks are checked out atomically so two agents never do the same work twice.

↻Scheduled heartbeats

Wakeups every 4, 8, or 12 hours keep the org running while you sleep.

Who built it

Created by Dota, Devin Foley (early Slack / Figma), and Scott Tong (former Head of Product Design at Pinterest). Featured on Greg Isenberg's podcast.

The Problem

20 terminals is not a management strategy

Running a fleet of coding agents used to mean a wall of terminal tabs, no delegation structure, and a token bill nobody was watching.

Before Paperclip
  • Developers juggle 20-30 open terminal sessions and lose track of what each agent is doing.
  • Runaway token spend with no automatic stop - a looping agent quietly burns the budget.
  • No task delegation structure: no tickets, no ownership, no reporting lines.
  • Agent conflicts and context resets whenever the machine reboots.
After Paperclip
  • One open-source management control plane for zero-human AI companies.
  • Org charts and ticketing give every agent a role, a queue, and a manager.
  • Atomic task execution plus heartbeats keep work moving without double-work.
  • Budget caps per agent enforce a spending ceiling across multiple agent frameworks.
The core reframe: stop babysitting terminals and start running your agents like an organization - hire them, assign them, budget them, and let the heartbeat schedule keep the company alive between your check-ins.
Setup

From zero to org chart

A managed one-line install, or run it from source with pnpm. Then connect the agent CLIs you already have installed.

1Managed CLI quickstart

curl -fsSLO https://paperclip.ing/install.sh && bash install.sh

Non-interactive setup (optionally bind to your LAN or tailnet):

paperclipai onboard --yes
# or: paperclipai onboard --yes --bind lan
# or: paperclipai onboard --yes --bind tailnet

Prefer npx? Try it without the installer:

npx --registry https://registry.npmjs.org paperclipai onboard --yes

2Manual / source setup

git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev

This starts the API server at http://localhost:3100 and creates an embedded Postgres.

3Connect your agents

Paperclip connects locally installed agent CLIs and bots. Assign specific models and set token budgets per agent or per company in the UI.

Claude Code

Connects as a locally installed agent CLI. Assign it Sonnet 4.6 or Opus 4.6 in the UI, then set its token budget so a runaway session halts automatically.

ChatGPT / Codex

Connects the OpenAI Codex CLI the same way. Assign GPT-5.4 (or a free OpenRouter model) and its own budget cap in the UI.

Gemini

Paperclip attaches to any agent CLI or HTTP bot, so a Gemini-based CLI connects like the rest. Free OpenRouter models are also assignable from the UI for budget-friendly seats.

Others (Cursor, OpenCode, OpenClaw, HTTP bots)

Cursor and OpenClaw connect as local CLIs; OpenCode connects via OpenRouter; anything else can join as an HTTP bot. Every seat gets a model assignment and a token budget.

Use Cases

Who is actually running agent companies

Not just developers: solo entrepreneurs, digital agencies, roofing companies, dentists, and security firms use Paperclip to orchestrate 20-30 simultaneous coding and marketing agents into structured org charts.

One dashboard instead of a terminal wall

Paperclip replaces chaotic multi-tab terminal setups with a unified dashboard tracking tasks, tickets, and session histories - and it all survives reboots.

Spending that stops itself

Monthly token budget caps per agent halt overspend automatically, preventing the runaway-loop costs that plague unattended agent fleets.

Around-the-clock output, zero double-work

Atomic task checkouts plus scheduled heartbeats (every 4, 8, or 12 hours) keep agents working continuously without two agents ever picking up the same ticket.

In the wild: a company built on top

Indie builder Evan Drake shipped Opensoul - a pre-configured Paperclip deployment for marketing with 6 agents (Director, Strategist, Creative, Producer, Growth Marketer, Analyst) running on scheduled heartbeats and delegating to each other. Real downstream production use of Paperclip as infrastructure. Show HN

Greg Isenberg ran a live demo with co-founder Dotta as the repo passed 30K stars in under 3 weeks (founder on camera, so partly promotional - YouTube). Metics Media's full "zero-human company" build covers install, Codex/Claude backends, and hiring a CEO agent (tutorial). Bini Inc runs its own public deployment repo (GitHub). One caution: the hosted "paperclip.ai" product is a different company - this repo lives at paperclip.ing.

⚠ Watch out for

  • "Momento man" syndrome. Agents wake up at every heartbeat with fresh context and need detailed instruction checklists to remember their role and task history.
  • You are still the board. Paperclip requires ongoing board-level oversight and prompt tuning from the human operator - this is management software, not magic.
  • Maximizer mode is unproven. Fully autonomous "maximizer mode" remains a work-in-progress; do not bet the company on it yet.
  • Taste is not automated. Agent design decisions and code taste still require human review before they ship.
