Single best feature

/grill-with-docs

An interactive grilling session that relentlessly interviews the developer upfront to resolve ambiguities and lock in a shared domain vocabulary in CONTEXT.md - before writing any code. Alignment first, implementation second.

The problem it solves

AI coding agents ship fast and misunderstand faster. Skills exist to fix the alignment gap.

Before

Communication misalignment. Agents frequently do not do what the user actually wants.

Extreme verbosity, zero jargon. Agents write walls of prose without understanding domain-specific vocabulary.

Non-working code. Without test feedback loops, agents produce code that simply does not run.

Accelerated entropy. Unchecked agent output turns codebases into a complex "ball of mud."

After

Grill before you build. /grill-with-docs interviews you upfront, resolving ambiguity and locking a shared domain vocabulary into CONTEXT.md.

Compressed domain language. A shared vocabulary condenses 20-word descriptions into concise domain terms - like "materialization cascade" - saving reasoning tokens in every subsequent session.

Classic engineering discipline. Small, composable skills like /tdd ground the agent in practices that predate it - and outlast it.

Architecture as a skill. /improve-codebase-architecture pushes back against entropy instead of accelerating it.

Set it up

One plugin for Claude Code, one universal installer for everything else, and a one-time setup command per repository.

Claude Code

Plugin install

From your terminal:

claude plugins install mattpocock-skills

Or directly inside a session:

/plugin install mattpocock-skills
ChatGPT / Codex

Universal installer

npx skills@latest add mattpocock/skills

An interactive CLI lets you pick specific skills, target agent harnesses, install scope (project vs. global), and symlink preferences.

Cursor + Other Agents

Same installer, pick your harness

npx skills@latest add mattpocock/skills

The interactive picker targets your agent harness of choice - Cursor and other agents are selected during the same flow.

Then, once per repo

Initialization

In your AI agent session, run:

/setup-matt-pocock-skills

It prompts for your issue tracker preference (GitHub, Linear, or local Markdown), triage labels, and domain documentation layouts.

Config & storage: writes configuration into CLAUDE.md and saves issues/specs into docs/agents/ or local .md files.

API keys: none required - it leverages your underlying agent harness.

Software engineers on both greenfield and brownfield codebases, using skills like /grill-with-docs, /tdd, and /improve-codebase-architecture to align with agents, establish domain models, and refactor complex codebases.

Watch out for

  • Higher cognitive load on you. User-invoked skills mean the human developer must know the skill library deeply to invoke the right tool manually.
  • "Skill hell." Unguided adoption can lead to developers stacking unvetted community skills without understanding how they interact.
  • Clunky installer navigation. The Vercel skills.sh interactive CLI has been noted as clunky when navigating large skill sets.
