/ The Problem

Out-of-the-box coding agents are talented juniors with no process. gstack gives them a sprint.

Before

Agents wander. Without structure, out-of-the-box coding agents guess without knowing project context and silently break code.

Terminal sprawl. Developers managing dozens of parallel terminal windows lost track of tasks and burned through token budgets.

Manual browser QA. Every UI change meant a human clicking through the app by hand to verify nothing broke.

After · with gstack

A structured sprint process. 23 opinionated tools enforce think, plan, build, review, test, ship - Claude Code operates like a virtual full-stack engineering team.

Product planning to code review, covered. The team spans product planning, design reviews, code reviews, and automated browser QA.

The agent tests its own UI. Native headless browser automation runs QA at roughly 100ms per command - no more tedious manual click-throughs.

/ Setup

One clone and a setup script. Solo, team mode, or any of the supported agent hosts.

1

Claude Code

git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup

Setup updates CLAUDE.md or AGENTS.md with skill routing entries. Persistent configuration lives in ~/.gstack/config.yaml.

2

ChatGPT / Codex

Clone to ~/gstack, then run setup with the Codex host flag:

./setup --host codex
3

Other hosts (Cursor, OpenCode, Factory, Kiro, Hermes)

Same pattern - clone to ~/gstack and pass your host:

./setup --host cursor
./setup --host opencode

OpenClaw: install via ClawHub instead:

clawhub install gstack-openclaw-office-hours gstack-openclaw-ceo-review gstack-openclaw-investigate gstack-openclaw-retro
4

Team mode (shared repos)

Inside your repository:

(cd ~/.claude/skills/gstack && ./setup --team) && ~/.claude/skills/gstack/bin/gstack-team-init required && git add .claude/ CLAUDE.md && git commit -m "require gstack for AI-assisted work"
5

Memory & API keys

Run /setup-gbrain to connect persistent memory via a local PGLite database or a Supabase Personal Access Token / Session Pooler URL.

For background runners or Conductor workspaces, set GSTACK_ANTHROPIC_API_KEY or GSTACK_OPENAI_API_KEY.

Browser QA at machine speed. gstack's native headless browser automation replaces the sluggish Claude-in-Chrome MCP, letting the agent verify its own work on the live app.

  • Deep reviews take time. Interactive reviews like /office-hours or /plan-devex-review require answering dozens of forcing questions, which can feel time-consuming.
  • Parallel sprints need orchestration. Managing multiple parallel agent sprints requires external workspace tools like Conductor to prevent context-switching chaos.
  • Windows friction. Bun hits Playwright pipe transport bugs (bun#4253), forcing a fallback to Node.js and non-symlink file copies that require manual setup re-runs after every git pull.
