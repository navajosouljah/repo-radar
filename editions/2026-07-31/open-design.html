★ Single best feature

Brand-backed design system integration: DESIGN.md + 151 bundled packages

Open Design forces AI-generated UIs, decks, and prototypes to adhere strictly to real brand tokens, colors, and typography. No more off-brand AI slop - the agent designs inside the rails of an actual design system, whether that is Stripe's, Linear's, Spotify's, or your own.

What was broken

AI design tooling existed - but it was closed, cloud-bound, and married to a single model. Open Design is the community's answer.

Before · the status quo
  • Anthropic's Claude Design is locked behind a paid subscription.
  • Restricted to a cloud-only environment - nothing runs on your own machine.
  • Tightly bound to a single proprietary model with no multi-model flexibility.
  • No repository integration, so design work stays cut off from your actual codebase.
After · with Open Design
  • Open-source, local-first desktop app and CLI - free to run on macOS, Windows, or Docker.
  • Turns any local coding agent into a design engine across 25 supported CLI executables.
  • Generates web/mobile prototypes, slide decks, live dashboards, images, and HyperFrames motion graphics (HTML to MP4).
  • DESIGN.md plus 151 bundled brand packages keep every output on real brand tokens, colors, and typography.
Why it matters

Design tooling should be as open as the code it designs for

Better Stack's coverage of the project is titled "Why 40k Developers Abandoned Claude Design" for a reason: when the paid, cloud-only, single-model option met an open local-first alternative with brand systems built in, the community moved. The repo now sits at 82.9K stars with 444 contributors.

Get it running

Four paths in: the zero-config desktop app, the agent/MCP CLI, Docker, or straight from source.

1Desktop app (zero config)

Download the native installer for macOS, Windows, or Linux from open-design.ai. No terminal required.

2Agent skill / MCP integration (CLI)

One installer wires Open Design into the coding agent you already use. Pick your agent below.

Claude Code

od mcp install claude
# or, via the install script:
curl -fsSL https://open-design.ai/install.sh | sh -s claude

ChatGPT / Codex

od mcp install codex
# or, via the install script:
curl -fsSL https://open-design.ai/install.sh | sh -s codex

Gemini

Gemini models connect as a model provider: configure your Gemini API key via the Welcome Daemon UI or environment variables, alongside OpenAI, Anthropic, Azure, Ollama, Atlas Cloud, and Minimax.

Others (Cursor, Copilot, OpenClaw, OpenCode, Antigravity, Hermes, Kimi...)

od mcp install <agent>
# where <agent> is one of:
# cursor · copilot · openclaw · opencode · antigravity · hermes · kimi ...

3Docker

git clone https://github.com/nexu-io/open-design.git
cd open-design/deploy
cp .env.example .env
echo "OD_API_TOKEN=$(openssl rand -hex 32)" >> .env
docker compose up -d

Then open http://localhost:7456.

4Run from source

Requires Node v24+ and pnpm 10.33.x.

corepack enable
pnpm install
pnpm tools-dev run web

5API keys

Configure provider API keys (OpenAI, Anthropic, Gemini, Azure, Ollama, Atlas Cloud, Minimax) and media keys (11Labs, Fish Audio) through the Welcome Daemon UI or via environment variables.

In the wild

Created by Tom and the Nexa team as the open-source alternative to Claude Design, and put through its paces by WorldofAI and Better Stack.

Prototypes, dashboards, and decks from one workspace

Developers and designers use Open Design to generate single-page HTML prototypes, live KPI dashboards, pitch decks, HyperFrames motion graphics (MP4), and full brand design systems - with exports to HTML, PDF, PPTX, MP4, ZIP, and Markdown.

A complete newsletter, agent-built

A full 5-page newsletter prototype was generated via local CLI agents in 5 to 20 minutes - drafted, laid out, and export-ready without leaving the local machine.

Brand systems as guardrails

With 151 brand-grade design system packages (Linear, Stripe, Spotify, Notion, and more), 100+ functional skills, and 277 official plugins, teams point their agents at a real design language instead of hoping the model improvises something on-brand.

Motion graphics without a video editor

HyperFrames renders HTML to MP4 at 1920×1080, 30fps - motion graphics produced by the same agent pipeline that builds the prototypes and decks.

⚠ Watch out for

  • Option overload. The vast array of configuration options, CLI settings, and design choices can feel overwhelming for non-designers.
  • Slow with non-frontier models. Generation times can drag when paired with open-source or non-frontier models - GLM 5.1 took roughly 20 minutes in testing.
  • macOS name collision. The system's native /usr/bin/od octal-dump binary can shadow the od CLI unless explicit PATH settings snippets are configured.
