Room II · The Hall of Forgetting

Agents that wake up with amnesia

What was broken before MemPalace, and how the palace restores what other memory systems quietly throw away.

Before · The Ruin

AI coding agents lose context across separate chat sessions and compaction events. They repeat the same mistakes, and they forget past architectural decisions the moment a session ends.

Worse, the existing memory tools paraphrase text through an LLM before storing it - silently dropping critical edge cases, technical constraints, and time-bound context. The memory you saved is not the memory you get back.

After · The Palace

MemPalace stores verbatim conversation history in drawers, organized in a Wing/Room/Hall hierarchy, indexed by a temporal SQLite knowledge graph - all local, all lossless.

What went in is exactly what comes out: the precise wording of the bug fix, the constraint, the decision - with its validity window attached. The agent stops relearning its own project every Monday.

The Restoration Principle

The architecture is the fix. Summaries compress by discarding; a palace compresses by organizing. Hierarchy plus verbatim drawers means recall is a lookup, not a reconstruction - and nothing of consequence is lost in translation.

Room III · The Builder's Atelier

Raising your own palace

Install, initialize, mine your history, then wire the palace into your agent of choice.

Step I · Install

Recommended package install (uv), or pipx:

uv tool install mempalace
# or
pipx install mempalace

Docker option:

docker build -t mempalace .
docker run -i --rm -v mempalace-data:/data mempalace
Step II · Initialize & Mine

Initialize in your repository, then ingest project files and past conversation transcripts:

mempalace init ~/projects/myapp
mempalace mine ~/projects/myapp
mempalace mine ~/.claude/projects/ --mode convos
Step III · Wire Into Your Agent

Claude Code

Wire auto-save hooks in .claude/hooks, or connect via the MCP stdio server:

"command": "mempalace", "args": ["mcp"]

ChatGPT / Codex

Same pattern: wire auto-save hooks in .codex, or use the identical MCP stdio configuration:

"command": "mempalace", "args": ["mcp"]

Gemini & other MCP-capable agents

The content sources document no Gemini-specific installer; connect through the standard MCP stdio server shown above.

Others · Cursor IDE

Add .cursor/rules plus the mempalace-recall skill to your project.

Step IV · Configuration & Keys

Core semantic recall requires no API keys. It runs on embedded local models such as embeddinggemma-300m.

Configure via ~/.config/mempalace/config.json or MEMPALACE_BACKEND environment variables if switching storage backends: chroma, sqlite_exact, milvus, qdrant, or pgvector.

Room IV · The Visitors' Ledger

Who walks these halls

Documented recall in the field, with the honest cracks in the marble recorded alongside.

The Curators & Their Guests

Created by Ma and Ben, and tested by Mansel Scheffel (Atomic Ops) and Better Stack. Developers use it to mine, index, and retrieve verbatim project history, Slack conversations, and Claude Code JSONL transcripts across separate chat sessions - so the agent that starts today remembers what the agent decided in March.

Exhibit B · Measured Recall
  • 96.6% R@5 raw retrieval recall on LongMemEval using 100% local semantic search - 0 API calls, no LLM required.
  • 355 MB mined in 32 minutes: Mansel Scheffel ingested 186 historical Claude JSONL conversations into 33,000 drawers, then accurately recalled exact late-March bug fixes and personal career context.
  • AAAK rule-based compression reduces the stored context token footprint while preserving full verbatim drawers for exact recall.
⚠ Watch Out For · Cracks in the Marble
  • Mining is time-intensive on large historical chat directories - 32 minutes for 355 MB in Scheffel's test.
  • Auto-classification can mislabel minor entity details on occasion, such as misfiling a school community name.
  • Overkill for small projects - where a few local Markdown files would suffice, the palace is unnecessary overhead.
  • No administrative UI for managing database backups, permissions, or multi-device sync.
  • Lookalike malware domains exist due to its viral growth - verify your installation source strictly before running anything.
