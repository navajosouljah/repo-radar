#8 this weekboykopovar/AnyPS5

AnyPS5

A tool that converts PlayStation 5 game files into programs that run directly on your Windows or Linux computer - no emulation needed.

Point it at a PS5 game's executable files and it produces a native Windows or Linux program, the way Valve's Proton layer lets Steam games run on Linux - but for PlayStation 5 titles.

How does it work?

Your problem

PS5 games only run on a PlayStation 5. If you want to play them on your computer, there is no official way, and traditional emulators are years from running modern 3D titles at playable speeds.

A PS5-exclusive game you want to play on your PC - there is no port, no official plan, and emulators can barely load the main menu of most games.

When it kicks in

You run AnyPS5's converter on a PS5 game's program files, or use the web converter at boykopovar.github.io/AnyPS5 (files stay on your device).

Upload a game's executable files to the web converter, pick Windows or Linux, and download the converted program.

You give it

A PS5 game's decrypted executable files - the program and system module files from the game, which must be obtained separately from your own console.

A decrypted ELF executable, plus the sce_sys and sce_module folders from the game.

It does

It rewrites the game's code into a format your computer can run directly, and provides replacement system libraries that stand in for Sony's services.

  1. The relinker converts the PS5 executable into a native program for your system (a Windows .exe or a Linux binary)
  2. Replacement system libraries handle what Sony's software would - memory, file access, controller input, and audio
  3. The shader recompiler translates the game's graphics instructions into a format your graphics card understands
  4. Controller mapping supports PS5 controllers, Xbox controllers, and keyboard/mouse through a configuration file

The PS5 uses the same type of processor as PCs (AMD x86-64), so the game's main code can run directly without translation - only the system libraries and graphics need to be converted.

You get

A native PC program that runs a PS5 game directly on your computer, without pretending to be a PlayStation.

  • A native PC programA Windows .exe or Linux program built from the PS5 game, running directly on your hardware
  • Controller supportPS5 DualSense controllers, Xbox controllers, and keyboard/mouse all work through a configuration file

What changes for me?

Without it

  • PS5 exclusives stay on the PS5. If there is no official PC port, the only options are buying the console or waiting years for emulators to mature.
  • PS5 emulators can barely reach a game's main menu. One leading emulator has 12 of 55 tested games reaching gameplay, and most crash early.

With it

  • A converter that rewrites PS5 executables into native PC programs - no emulation layer, so in theory far less overhead.
  • A web-based converter that runs in your browser and keeps all files on your device - no uploads, no servers, no installs required for conversion.

Effort

5 minutesAbout an hourNeeds a developer

Should I?

Great if you...

  • You want to follow the PS5-to-PC porting effort and try early builds as they mature - this is a front-row seat to a new approach
  • You are a developer interested in binary translation, shader recompilation, or system library reimplementation

Skip it if...

  • You want to play PS5 games on PC today - only one simple 2D game is confirmed working, and no 3D titles are playable yet
  • You do not have legally obtained PS5 game files from your own console - the project ships no games, firmware, or extraction tools
  • You want a polished experience - there are no prebuilt installers, and the project is 74 days old

Instead, you could look at

  • Official PC portsSony has been bringing PS5 exclusives to PC officially - Marvel's Spider-Man 2, God of War Ragnarok, and others are already on Steam.
  • PS Remote PlaySony's official app streams PS5 games to your PC, phone, or tablet over your network. Requires a PS5 and a good connection.

Is it safe?

PASSED
  • Security advisories: 0GitHub's advisory list, checked Oct 16
  • Searches for CVEs, vulnerabilities, malware and scams2 results read, including the national CVE database: nothing found
  • Are the stars earned?39.3K stars, 364 contributors, 8.9K commits. No findarepo data found. Covered by Tom's Hardware, TweakTown, Notebookcheck, and VideoCardz.

Watch out for

  • Only one game is confirmed playable. Dreaming Sarah, a small 2015 2D platformer, is the only title that runs start to finish. No 3D game is playable yet. 100% shader coverage is a milestone, but system library reimplementation is at about 85% and many functions are stubs.
  • Requires game files from a modified console. AnyPS5 ships no games, no firmware, and no extraction tools. Getting the files typically means dumping them from a jailbroken PS5, which may violate your console's terms of service or local laws.
  • Extremely early - expect crashes. The project is 74 days old and has shipped only v0.1. Its own demo shows a game reaching menus and early gameplay before crashing. The developer says releases will follow only after a full game launch.
  • Progress percentages are misleading. The shader and library coverage numbers track only the functions the project has catalogued so far, not every PS5 system function. The true denominator grows as more games are tested.
