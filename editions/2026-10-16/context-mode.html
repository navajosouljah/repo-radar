Context Mode

How does it work?

Your problem

Your AI coding agent's conversation fills up fast. Every test output, log file, and code search it reads eats into a fixed-size working memory, and after about 30 minutes the agent has to compress or start over.

You ask your agent to run a 600-line test suite. The raw output is 56 KB - and now a quarter of the agent's memory is gone on one result.

When it kicks in

You install Context Mode once - it runs as a background service (an MCP (Model Context Protocol) server, a bridge that gives AI agents extra tools) and starts intercepting tool results automatically.

One command in your terminal, or install from the Claude Code plugin marketplace. It activates automatically for every session.

You give it

The raw output from tools your agent uses: test results, log files, search results, file contents - anything the agent would normally read in full.

A Playwright browser snapshot (56 KB), 20 GitHub issues (59 KB), or a server access log (45 KB).

It does

It intercepts tool output before the agent sees it, runs it in an isolated process, and hands back only a small summary.

  1. Runs each tool's output in a sandboxed process so the raw data never enters the conversation - only the printed result does
  2. Indexes the full output in a local database so the agent can search it later by keyword if it needs more detail
  3. Tracks file edits, decisions, and task progress in a session log that survives compression, so the agent remembers what happened

47 file reads totaling 700 KB become one sandboxed call returning 3.6 KB - the agent gets what it needs without filling its memory.

You get

Longer, cheaper AI coding sessions with less wasted memory.

  • Longer sessionsA session that used to compress at 30 minutes runs for about 3 hours before needing to compress
  • Lower costsA long Claude Code session on Opus 5.5 dropped from $7.20 to $2.49 in the project's paired tests (155 of 168 runs cost less)
  • Resumable workAfter compression, a 2 KB snapshot restores the agent's awareness of what happened earlier in the session

What changes for me?

Without it

  • Your AI coding agent fills its working memory after about 30 minutes of real work. It has to compress or start over, losing track of what it was doing.
  • Every tool result enters the conversation at full size - a 56 KB test snapshot, a 59 KB batch of issues - even if the agent only needed a one-line answer from each.

With it

  • Tool results are processed in the background and only summaries enter the conversation. A 315 KB session becomes 5.4 KB, and the full data is still searchable.
  • Sessions run for hours instead of minutes, and the agent picks up where it left off after compression because its decisions and progress are saved locally.

Should I?

Great if you...

  • You run long AI coding sessions and hit context limits regularly - especially sessions over 30 minutes that compress and lose track of earlier work
  • You want to reduce your AI coding costs without changing how you work - install once and the savings happen automatically

Skip it if...

  • You mostly run short sessions that finish in a few minutes - the overhead of indexing and sandboxing adds no value for quick tasks
  • You need a fully open-source tool - Context Mode changed from MIT to the Elastic License 2.0, which is source-available but not open-source, and cannot be offered as a hosted service
  • You work on Windows - an open issue reports a batch execution call that ran for over four hours without completing

Instead, you could look at

  • Curated tool listsReduce context by loading fewer tools. Context Mode handles output size; this handles input size. They work together.
  • Context Mode Engine (free)The free local plugin with sandbox and index. The paid Context Mode gateway ($49/month) adds cost controls, team policies, and analytics.

Is it safe?

PASSED
  • Security advisories: 0GitHub's advisory list, checked Oct 16
  • Searches for CVEs, vulnerabilities, malware and scams9 results read, including the national CVE database: nothing found
  • Are the stars earned?30K stars, 120 contributors, 2.2K commits. No findarepo data found. GitHub trending confirmed by multiple sources.

Watch out for

  • License changed from MIT to Elastic License 2.0. ELv2 is source-available, not open-source. You can use and modify it freely, but you cannot offer it as a hosted service to others.
  • The 98% claim measures bytes saved, not answer quality. The developer says 'We haven't run formal benchmarks on answer quality yet.' Fewer bytes in context could mean the agent misses details. An independent reviewer recommends checking your own numbers with /context-mode:ctx-stats.
  • Windows support has known issues. A GitHub issue (#947) reports a batch execution call that stayed in flight for over four hours. The reviewer advises Windows users to check the issue tracker first.
  • Adoption claims are self-reported. The README shows badges for Microsoft, Google, Meta, Amazon, and others, but an independent review found these come from the project's own tracking file and could not be confirmed.
