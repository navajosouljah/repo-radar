How does it work?

Your problem

You want your AI coding agent to follow specific practices - design standards, testing rules, coding conventions - but writing those instructions yourself takes time, and they don't transfer between agents.

You wrote a page of design guidelines for Claude Code, but now you want the same rules in Cursor and Codex - and each agent stores instructions in a different folder.

When it kicks in

You run a command in your terminal and pick a skill from the directory at skills.sh.

Type npx skills add vercel-labs/agent-skills and Vercel's official skill pack installs into every agent on your machine.

You give it

A skill name or search term - a GitHub project like vercel-labs/agent-skills, or a keyword like 'react testing'.

npx skills find typescript searches the directory and shows matching skills with their install counts.

It does

It finds the skill, downloads it, and installs it into the right folder for each of your AI coding agents.

  1. Finds the skill in the skills.sh directory (over 600K skills listed) or directly from GitHub, GitLab, or a URL
  2. Downloads it and places it in the correct folder for your agents - Claude Code, Cursor, Codex, or any of 75+ others
  3. Your agent loads the skill automatically when a matching task comes up - full instructions load on demand, not all at once

The README's example: install a 'react testing' skill and the next time you ask your agent to write tests for a React component, it follows the skill's testing practices automatically.

You get

Your AI coding agents have new, shared abilities - installed once, available across every supported agent on your machine.

  • Skills installed across agentsOne install command puts a design skill into Claude Code, Cursor and Codex at the same time
  • A searchable directoryskills.sh lists over 600K skills with install counts, categories and security scans from Snyk
  • Your own skillsnpx skills init creates a template - write instructions once and share them with your team or publish them to the directory

What changes for me?

Without it

  • Adding a new ability to your AI coding agent means writing instructions from scratch, and those instructions only work in one agent - switching agents means rewriting them.
  • There is no central place to find, compare or share ready-made agent instructions. You copy snippets from blog posts and hope they work.

With it

  • One command installs a skill into every agent on your machine - Claude Code, Cursor, Codex and 75+ others, all at once.
  • A searchable directory at skills.sh lists hundreds of thousands of skills, ranked by installs, with categories and security scans.

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Search for a skill: run npx skills find react (or any topic you care about) in your terminal and browse the results.
  2. Install one: run npx skills add vercel-labs/agent-skills to install Vercel's official skill pack into your agents.
  3. Check it worked: run npx skills list to see which skills are installed and which agents they landed in.

What it takes on your computer

Space on disk
No permanent install needed. Runs via npx (requires Node.js). Skills themselves are small text files - a SKILL.md plus optional scripts and references.
Memory while it runs
No data found. The tool runs briefly to install or search, then exits. Skills are loaded by the agent, not by the tool.
Runs on
Mac, Windows and Linux. Requires Node.js (for npx). The tool installs skills for whichever agents are already on your machine.

Should I?

Great if you...

  • You use an AI coding agent and want to add abilities - design taste, testing rules, coding standards - without writing instructions from scratch
  • You work across multiple agents (Claude Code, Cursor, Codex) and want the same skills in all of them with one install command

Skip it if...

  • You already have a well-tuned set of agent instructions and don't want a tool overwriting or conflicting with them
  • You are concerned about running unreviewed third-party instructions in your coding agent - the directory has no human review gate

Instead, you could look at

  • Agent Skills specificationThe open standard behind skills. You can write and install SKILL.md files by hand without the skills tool or the skills.sh directory.
  • Agent-specific instructionsWrite instructions directly for one agent: CLAUDE.md for Claude Code, .cursorrules for Cursor. More control, but no cross-agent sharing.

Is it safe?

PASSED
  • Security advisories: 0GitHub's advisory list, checked Oct 16
  • Searches for CVEs, vulnerabilities, malware and scams20 results read, including the national CVE database: nothing found
  • Are the stars earned?35.2K stars, 157 contributors, 570 commits. No findarepo page found for this project

Watch out for

  • No human review gate. Skills.sh lists over 600K skills with no submission or curation process. Rankings come from install counts alone, which one independent reviewer notes 'can be gamed.'
  • Security researchers bypassed the malicious-skill detector. Trail of Bits got data-exfiltrating skills marked safe. Vercel's response is a real-time scanning partnership with Snyk rather than human review.
  • Skills run inside your agent with your permissions. A skill's instructions become part of what your agent does. Review what you install, especially from unknown publishers.
  • The ecosystem is 9 months old. The format started at Anthropic and was released as an open standard in December 2025. Adoption is broad (75+ agents, 20+ platforms) but the trust model is still maturing.
