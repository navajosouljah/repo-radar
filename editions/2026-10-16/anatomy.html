Anatomy

How does it work?

Your problem

You want to explain how a machine or system works, but drawing a clear, labeled diagram by hand takes hours - and a screenshot or stock image does not show the insides.

You are writing docs for a caching system and want a picture that shows how the parts fit together, not just a box-and-arrow chart.

When it kicks in

You type a one-line request in Claude Code (or another supported coding agent) and the skill takes over.

Type '/anatomy explain how a pin-tumbler lock works, interactive' and the agent starts building.

You give it

A plain-English description of the machine or idea you want illustrated.

'Explain how a Raptor 2 rocket engine works' - one sentence is enough.

It does

Claude writes a computational model with real values, then draws each part as a shaded solid and wires them together into a moving figure.

  1. Writes the working values (pressures, temperatures, speeds) as a model that drives the motion and the readout
  2. Draws 40 to 150+ parts with four-tone shading, assembles them in the right order, and adds labels
  3. Runs a geometry audit to check that no parts overlap or pass through each other, then takes screenshots to verify the result

The Raptor 2 example: 11 assemblies, a WebGL exhaust plume, and a live readout showing chamber pressure and thrust.

You get

An interactive diagram you can open in a browser, embed in docs, or drop into a React app.

  • Standalone HTML pageA single file you open in any browser - hover the engine to take it apart, see each part labeled
  • SVG file or React componentDrop a component into your Next.js docs site with working interaction and keyboard support
  • Optional WebGL effectsFire, water, exhaust, lamp glow and steam layered into the diagram for realism

What changes for me?

Without it

  • Explaining how a machine works means drawing a diagram by hand, paying a technical illustrator, or settling for a flat screenshot that does not show the insides.
  • A box-and-arrow chart gets the topology across but does not show what the parts look like or how they move.

With it

  • Describe what you want in one sentence and get an interactive picture where every part is labeled, moves realistically, and shows live numbers.
  • The diagram is source code you own - a standalone HTML file, an SVG, or a React component you drop into your docs.

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Install the skill: run npx skills add wheresryan22/anatomy -g (requires Node.js 20.10+). If you use Claude Code, add -a claude-code.
  2. In Claude Code, type /anatomy explain how a dial indicator works, interactive. The agent will build a figure - a small one takes 30-90 minutes of agent time.
  3. View the result in your browser. Hover the parts to see them labeled, click to take them apart, and check the live readout.

What it takes on your computer

Space on disk
About 10 MB for the skill folder (including examples). No additional packages to install - uses only Node.js built-in modules.
Memory while it runs
No data found. Chrome or Chromium is needed only for the visual verification step. WebGL is needed for shader effects but the plain SVG renders without it.
Runs on
Any system that runs a supported coding agent (Claude Code, Antigravity, OpenCode, Codex, MiniMax Code) and Node.js 20.10+. Output works in any modern browser. Reduced-motion mode stops all animation.

Should I?

Great if you...

  • You want to explain a machine or system visually and do not want to draw it yourself - one sentence in, interactive diagram out
  • You are writing technical docs or a presentation and want a labeled, interactive figure you can embed as HTML, SVG or a React component

Skip it if...

  • You need a chart with axes and data plots - this draws machines and instruments, not bar charts or line graphs
  • You need a quick illustration in minutes - a single figure takes 30 minutes to 2+ hours of agent time, and complex ones (a turbofan engine) took 14 hours in one test

Instead, you could look at

  • MermaidText-to-diagram tool for flowcharts, sequence diagrams and architecture charts. Fast and widely supported, but draws flat boxes and arrows, not shaded machines.
  • ExcalidrawA free whiteboard for hand-drawn-style diagrams. Good for quick sketches, but you draw by hand - no AI generation.
  • draw.io (diagrams.net)A free diagram editor with shape libraries. More control over layout, but no isometric shading or interactive disassembly.

Is it safe?

PASSED
  • Security advisories: 0GitHub's advisory list, checked Oct 16
  • Searches for CVEs, vulnerabilities, malware and scams20 results read, including the national CVE database: nothing found
  • Are the stars earned?13.5K stars, 14 contributors, 152 commits. findarepo: looks organic (100/100)

Watch out for

  • Figures take a long time to build. A small dial gauge takes 30-90 minutes of active agent time. A Raptor 2 engine took over 10 hours. A turbofan took 14 hours. Each hour uses Claude Code usage quota.
  • This is not an engineering simulation. The diagrams look detailed, but one reviewer notes they do not establish engineering accuracy, manufacturing suitability, or a validated simulation. The numbers shown are illustrative, not certified.
  • 8 days old - no production use yet. The repo was created October 8, 2026. No named users or teams have reported using it in production. Stars show interest, not adoption.
  • Review the skill before installing. It runs Node scripts and a headless Chrome browser locally. The publish script reads duration and token usage from session logs unless you pass --no-session.
