How does it work?

Your problem

You see software you admire but can't build your own version of it.

When it kicks in

You paste a URL or point it at an app and say 'Recreate this.'

You give it

A website URL, an app, a game, or a file you want to study and rebuild.

It does

The app studies the target, has a coding agent build a new version, and refines it.

  1. Studies the target - takes screenshots at every width, reads visible text and layout
  2. A coding agent (like Claude Code) builds a new project in your chosen language
  3. Compares the build with the original and lists mismatches
  4. Refines until the comparison check passes
You get

A working project you own, built from scratch.

  • A recreated projectPaste a website URL and get a working copy in your chosen language, checked against the original
  • A comparison reportThe app found 2 mismatches (missing footer, wrong font) and fixed them in a second pass

What changes for me?

Without it

  • You see a website or app you like and try to code something similar from scratch, guessing at behavior
  • Reverse engineering takes specialized tools and deep technical knowledge

With it

  • Point at any software and get a working recreation in your chosen language, checked against the original
  • Clean-room mode means you work only from visible material - screenshots and text - not source code

Should I?

Great if you...

  • Anyone who sees an app or website and wants their own version of it
  • People who want to learn how software works by rebuilding it
  • Non-coders who want a coding agent to do the building for them

Skip it if...

  • You need production-quality code - this is early alpha
  • You don't have a coding agent installed (Claude Code, Codex, or similar)
  • You want to copy source code directly - Craft Anything works from screenshots and visible text only

Instead, you could look at

  • HallmarkA design skill for web pages - focuses on making AI-built sites look hand-designed, not on recreating existing ones
  • UnslopFixes the generic look of AI-built interfaces pass by pass, rather than rebuilding from scratch

Is it safe?

PASSED
  • Security advisories: 0GitHub's advisory list, checked Nov 6
  • Searches for CVEs, vulnerabilities, malware and scams6 results read, including the national CVE database: nothing found
  • Are the stars earned?16.6K stars, 52 contributors, 357 commits

Watch out for

  • Early alpha. The README says so explicitly - expect rough edges and incomplete features.
  • Requires a coding agent. Craft Anything doesn't write code itself. You need Claude Code, Codex, or a similar agent installed and signed in on your machine.
  • Clean-room only. It works from screenshots and visible text, not source code. Results may not replicate behavior exactly.
  • Check your rights. Only use it on software you own or are allowed to examine. Recreating copyrighted software may have legal implications.
