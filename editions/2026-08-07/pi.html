● What makes it different

Self-extensible slash commands

Handwritten markdown docs (like extensions.md in node_modules) are exposed to the LLM via the default system prompt. Ask Pi for a feature and it writes and compiles the TS/JS extension itself, straight into your .pi directory.

/reload hot-reloading

Freshly compiled commands go live instantly - no restarting the terminal session, no destroying active thread history.

Unified multi-provider LLM API

The pi-ai package runs open-weight models like GLM 5.2 and Kimmy K3 alongside frontier proprietary models like GPT 5.5 on low reasoning.

/tree state traversal

Visually browse a structured history of past prompts, tool executions, and assistant responses inside the differential-rendering TUI.

Supply-chain hardening

Direct deps locked to exact versions, min-release-age=2 blocks same-day dependency exploits, and a pre-commit check blocks lockfile commits unless PI_ALLOW_LOCKFILE_CHANGE=1 is set.

Ephemeral context loading

Community patterns like Pi Ephemeral mount MCP servers and project-local skills on a single-turn basis - only when triggered, never squatting in context.

Single best feature

The agent builds its own harness

Ask a fresh Pi instance "how do I make a custom extension" and it reads the bundled extensions.md, writes the extension, compiles it, and after one /reload your new slash command is live - mid-session, without interrupting active threads. Neovim-level customization without the Neovim learning curve.

The problem it solves

Opinionated agent platforms ship heavy and customize hard. Pi inverts the trade: start bare, grow exactly what you need.

Before

Heavyweight opinionated defaults. Traditional agent systems (Open Code, VS Code-style platforms) bundle MCP, to-do systems, LSPs, and native undo engines whether you need them or not.

Rigid extension APIs. Customizing means a steep learning curve - and restarting the entire program just to test a minor command change.

Context window pollution. Global agent "skills" are permanently injected into the LLM context, wasting tokens and confusing models during unrelated tasks.

After

Four core tools, one clean TUI. Pi ships as a minimalist harness in the Neovim mold - configuration shifts entirely to the developer.

The agent extends itself. Tell Pi to build a slash command and it writes the extension into your .pi directory. /reload makes it live instantly, no restart.

Context stays clean. Ephemeral loading patterns mount local skills, prompts, or MCP servers on a single-turn basis, protecting precious context boundaries.

Set it up

Install via curl, PowerShell, npm / pnpm / bun, or the AUR on Arch Linux. Then log in, pick a model, and start extending.

1

Global install

npm i -g @earendil-works/pi

On Arch Linux, install the Pi coding agent package via yay from the AUR instead.

2

Log in and pick a model

Run pi in your project directory, then:

/login          # or /lo - OAuth or paste an API key (e.g. an Open Code Zen key)
/model GLM 5.2  # select your model
/settings       # tune reasoning depth (e.g. set GLM to maximum reasoning)
3

Install the essentials Pi deliberately leaves out

pi install npm pi-permission-system   # approval gateways
pi install npm pi-undo-redo           # rollback support
pi install npm pi-web-access          # web search

Then wire the policy: edit .pi/permissions.json so write/edit tools, bash, MCP, and skills ask first - while read-only commands like ls, git status, and git diff stay whitelisted.

4

Building from source (optional)

npm install --ignore-scripts   # deps without lifecycle scripts
npm run build                  # refresh model data + compile all packages
npm run build:offline          # rebuild with existing model catalogs
npm run check                  # lint, format, TypeScript checks
./pi-test.sh                   # run Pi directly from sources

Standalone binaries build from the release tarball via ./scripts/build-binaries.sh --offline-model-data --platform linux-x64.

Manual context hygiene that works. Users bypass long, messy conversational histories by extracting code and key details with /copy all, then spinning up a clean thread with /new - dropping the model's tool execution overhead.

Repetitive task elimination. The custom /yeet command has the agent stage changes, write the commit message, push to production, and even open pull requests autonomously.

Know the sharp edges

Minimalism cuts both ways. Pi's bare-by-default design pushes real security and safety work onto you.

Watch out for

  • No permission system out of the box. Pi will execute arbitrary shell and Python commands immediately, without asking - no filesystem, process, network, or credential restrictions. You must install pi-permission-system and hand-write .pi/permissions.json to get approval gates.
  • Incomplete undo mechanics. There is no native undo/redo. The community pi-undo-redo extension warns that in non-git mode it only restores files explicitly touched by Pi's native tools - changes made through shell commands are not restorable.
  • Extension supply-chain risk. Every extension install pulls an npm package or clones a GitHub repo. Read the extension code before installing - malicious code execution is a real exposure.
  • No web search or MCP included. Modern agent essentials are completely absent from the core. You build them yourself or lean on third-party scrapers like Firecrawl or Exa.
  • Global skills pollute context. Skills loaded globally sit in the prompt context permanently, degrading LLM performance even when they are never called - the reason the community reaches for ephemeral loading patterns.
