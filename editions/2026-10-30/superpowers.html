Superpowers

A set of rules that teach your AI coding assistant to plan first, test everything and debug carefully - like a senior engineer would.

How does it work?

Your problem

AI coding assistants rush straight into writing code - they skip planning, ignore edge cases, forget to write tests and produce sloppy work that breaks later.

When it kicks in

You install the skills once and they activate automatically every time you start a coding task.

You give it

Your coding project - any codebase you're working on with an AI assistant.

It does

The skills change how the AI assistant approaches every task - planning, building, testing and reviewing.

  1. Before coding, the assistant asks clarifying questions and drafts a design for your approval
  2. It writes a detailed plan, then works through it using test-driven development - tests first, code second
  3. When the code is done, it runs its own code review, catches issues, and only marks the task complete after verifying everything works
You get

An AI assistant that works like a careful senior engineer instead of a rushed intern.

  • A structured plan before any codeThe assistant writes a plan document with acceptance criteria, then asks you to approve it before starting
  • Tests written before featuresFor a new feature, it writes the test cases first, confirms they fail, then writes the code to make them pass
  • Self-reviewed codeBefore marking a task done, the assistant reviews its own changes, checks for edge cases and runs the test suite

What changes for me?

Without it

  • Your AI assistant dives straight into writing code without asking what you actually want
  • It produces code that works for the obvious case but breaks on edge cases nobody tested
  • You spend time reviewing and fixing mistakes the assistant should have caught itself

With it

  • The assistant asks questions first, writes a plan, and waits for your approval before coding
  • Tests are written before features - the assistant proves the code works, not just that it compiles
  • A self-review step catches common mistakes before you ever see the code

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. In Claude Code, run /plugin install superpowers@claude-plugins-official. For other tools, see the install guide - there are one-line installs for 16 AI coding tools.
  2. Start a new session and give it a task - for example, 'Let's make a React to-do list.' The assistant should start by asking clarifying questions instead of jumping into code.
  3. Follow the assistant's plan - it will write tests first, then code, then review its own work before marking the task done.

Should I?

Great if you...

  • Anyone using an AI coding assistant who wants more reliable, better-tested output
  • Teams that want their AI tools to follow a consistent development process
  • People new to AI-assisted coding who want guardrails on the assistant's behavior

Skip it if...

  • You prefer to control the process yourself and find pre-set workflows restrictive
  • You use AI for quick one-off scripts where planning overhead isn't worth it
  • Your team already has strict coding standards the AI follows

Instead, you could look at

  • mattpocock/skillsMatt Pocock's engineering skills - broader (55 skills) and more focused on day-to-day engineering tasks than methodology
  • ECCA performance optimization system for coding agents - focuses on speed and efficiency rather than methodology

Watch out for

  • Very opinionated. Superpowers enforces one specific development methodology (plan, test, review). If your team has its own process, the skills may conflict with it.
  • Adds overhead to quick tasks. The brainstorming and planning steps add time. For a one-line fix or a quick script, the ceremony can feel like overkill.
  • Works best with Claude Code. The README lists 16 tools, but the creator built and tested it primarily with Claude Code. Other tools may not trigger all skills correctly.
