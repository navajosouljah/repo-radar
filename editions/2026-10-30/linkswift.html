LinkSwift

A browser script that finds the real download link on Chinese cloud-storage pages so you can use your own download tool.

Install one script in your browser, open a Baidu or Aliyun cloud-storage shared link, and it shows the direct download address - so you can grab the file with any download manager instead of the provider's app.

How does it work?

Your problem

Someone sends you a file on Baidu, Aliyun, or another Chinese cloud drive, and you have to install their app to download it at a reasonable speed.

When it kicks in

You open the shared link in your browser, where the LinkSwift script is already installed.

You give it

The cloud-storage shared link someone gave you.

It does

The script reads the page and finds the file's real download address.

  1. Detects which cloud provider the page belongs to (Baidu, Aliyun, Quark, Xunlei, UC, 123 Cloud, China Mobile Cloud, or Tianyi Cloud)
  2. Calls the provider's own public download interface to get the direct file link
  3. Shows a download button with the direct link on the page
You get

A direct download link you can use with any download manager.

  • A direct download linkA full URL you can paste into your browser's download bar, IDM, or any download manager
  • No app requiredDownload the file directly instead of installing the Baidu Netdisk desktop app

What changes for me?

Without it

  • You have to install the cloud provider's desktop app just to download a file someone shared
  • Downloads through the web interface are throttled to slow speeds without a paid plan
  • Each provider has its own app, so you end up with 3-4 apps for occasional file downloads

With it

  • One browser script covers 8 cloud providers - no apps to install
  • Direct download links work in any download manager or browser
  • No account or login needed for files shared with a public link

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Install the Tampermonkey extension in your browser (Chrome, Firefox, Edge, or Safari)
  2. Install LinkSwift from GitHub by clicking the user.js file and hitting 'Install' in Tampermonkey
  3. Open a shared file link on Baidu Pan or any other supported cloud drive - the script adds a download button to the page

What it takes on your computer

Space on disk
A single JavaScript file, under 1 MB. Runs inside your browser's Tampermonkey extension.
Memory while it runs
Runs inside a browser tab - no separate process.
Runs on
Any browser that supports Tampermonkey or Violentmonkey: Chrome, Firefox, Edge, Safari. Works on desktop only.

Should I?

Great if you...

  • Anyone who receives files shared through Chinese cloud-storage services and wants to skip installing the provider's app
  • People who prefer using their own download manager instead of the provider's client

Skip it if...

  • You don't use Chinese cloud-storage services (Baidu, Aliyun, etc.)
  • You already have the provider's desktop app and are fine with it
  • You need to upload or sync files, not just download

Instead, you could look at

  • MotrixA free download manager that can use direct links once you have them
  • baiduyun (original)The original userscript LinkSwift is based on - Baidu-only, no longer actively maintained

Watch out for

  • Based on another developer's work. LinkSwift is a modified version of the original script by syhyz1990. The README does not clarify whether the original author consented to the fork.
  • Chinese-language only. The entire interface, documentation, and community are in Chinese.
  • Cloud providers change their systems. Direct-link scripts break when a provider updates its download API. The project has been maintained since 2022, but breaks are common.
  • Legal gray area. Extracting direct download links may violate some providers' terms of service. The project states it uses public APIs and does not bypass speed limits, but provider policies vary.
