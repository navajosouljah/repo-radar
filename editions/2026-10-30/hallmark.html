Hallmark

A design skill that teaches your AI coding tool to build web pages that don't look AI-generated.

Install one file, type /hallmark, and your coding assistant builds a web page using 50 real design themes with proper typography, spacing, and photography - then reviews the result in a browser to catch common AI-design patterns.

How does it work?

Your problem

When AI builds a web page, the result often looks generic - the same fonts, the same layout, the same stock-photo feel that screams 'a machine made this'.

When it kicks in

You type /hallmark followed by what you want to build, or /hallmark redesign to fix an existing page.

You give it

A description of the page you want, or a path to an existing page you want redesigned.

It does

The skill guides your AI through a design process, then reviews the result in a browser.

  1. Picks a theme from 50 material-based design systems (or creates a custom one from your prompt)
  2. Builds the page with proper typography, color, spacing, and about 755 openly licensed photos from Wikimedia Commons
  3. Opens the finished page in a browser and runs a lint pass to catch common AI design patterns
  4. Flags anything that looks machine-made (generic gradients, centered everything, stock-photo layouts) and fixes it
You get

A web page that looks like a designer made it.

  • A themed web pageA hotel website with serif typography, hand-illustrated artwork, and a color palette based on earth tones
  • A browser-verified designThe lint pass caught 3 AI-slop patterns (centered hero, generic gradient, no real photography) and fixed them

What changes for me?

Without it

  • AI builds a web page and it looks like every other AI-generated page - centered text, blue gradients, generic stock photos
  • You ask the AI to 'make it look better' and it changes colors but keeps the same boring layout
  • Hiring a designer for a one-page site costs time and money you don't have for a quick project

With it

  • 50 real design themes with distinct typography, color, and layout - not just color swaps
  • A browser-based lint pass catches common AI design patterns before you ship
  • One command to redesign or audit an existing page without starting over

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Install the skill: run npx skills add nutlope/hallmark -g in your terminal (needs Node 18+)
  2. Open Claude Code (or Cursor, Codex, or OpenCode) and type /hallmark followed by what you want to build - for example, /hallmark a landing page for a weekend pottery workshop
  3. Review the result - the skill opens it in your browser and runs a lint pass. To redesign an existing page, try /hallmark redesign index.html

Should I?

Great if you...

  • Anyone who uses AI to build web pages and wants them to look hand-designed
  • Non-designers who want real design themes, not just color changes
  • People who want to audit existing AI-built pages for generic patterns

Skip it if...

  • You already have a designer or a design system you follow
  • You don't build web pages with an AI coding tool
  • You need a full design tool, not a prompt skill - Hallmark guides the AI, it doesn't replace Figma

Instead, you could look at

  • ImpeccableA broader design vocabulary with 24 commands (polish, bolder, critique, audit and more) from the creator of jQuery UI
  • taste-skillA skill focused on giving your AI 'good taste' in design, with a different philosophy
  • ImpeccableA design vocabulary for your AI agent with polish, critique, and audit commands

Watch out for

  • Design is subjective. The skill enforces its own design opinions - 50 themes and a lint pass for 'AI slop'. Your taste may differ, and the AI still makes the final choices.
  • Browser checks need Chrome. The lint pass opens your page in a real browser. Static checks work without it, but the full review needs Chrome or Chromium installed.
  • No tagged releases. Install is via npx from the main branch. The skill updates whenever the repo changes.
  • The photos are openly licensed, but check the credits. Hallmark includes about 755 photos from Wikimedia Commons, each credited on the generated page.
