How does it work?

Your problem

AI assistants can't browse the real internet - they can't read Twitter threads, Reddit posts, YouTube transcripts or Chinese platforms like Bilibili.

When it kicks in

You ask your AI assistant to look something up on a specific platform - for example, 'search Twitter for reactions to the new iPhone.'

You give it

A search query or a URL from a supported platform (Twitter, Reddit, YouTube, Bilibili, GitHub, and others).

It does

It connects to the platform, fetches the content and returns it in a format the AI can read.

  1. Picks the right channel for the platform (Bilibili, YouTube, Reddit, etc.) or detects it from the URL
  2. Fetches the page content - search results, video transcripts, thread comments, or profile data
  3. Returns structured text the AI assistant can read and act on
You get

Real internet content your AI assistant can read, summarize and act on.

  • Platform search resultsA Bilibili search for a topic returns video titles, view counts and descriptions
  • Video transcriptsA YouTube video URL returns the full transcript (speech-to-text if no subtitles exist, using a Groq key)
  • Thread and post contentA Reddit URL returns the post text and top comments in plain text

What changes for me?

Without it

  • Your AI assistant is blind to the live internet - it can't read social media, watch videos or check what people are saying right now
  • Getting content from platforms like Bilibili or XiaoHongShu requires building custom scrapers or paying for API access
  • Each platform has its own format - there's no single tool that reads them all

With it

  • One command (agent-reach read <url>) fetches content from 10+ platforms and returns it as plain text
  • Most channels work without API keys - YouTube speech-to-text and podcast transcription need a free Groq key
  • Your AI assistant can now research across Twitter, Reddit, YouTube, Bilibili, GitHub, V2EX and more

Should I?

Great if you...

  • Anyone who wants their AI assistant to research topics across social media and video platforms
  • People who work with Chinese platforms like Bilibili and XiaoHongShu
  • AI agent builders who need live internet data without paying for API access

Skip it if...

  • You need guaranteed reliability - scraping can break when platforms change their pages
  • You only need web search - a simpler tool like Jina Reader covers basic web pages
  • You're concerned about terms of service - scraping social media may violate platform rules

Instead, you could look at

  • Jina ReaderReads any web page as clean text - simpler but doesn't handle platform-specific features like video transcripts
  • ExaAI-native search engine with an API - more reliable but requires an API key and has usage limits

Is it safe?

PASSED

  • Are the stars earned?107K stars, 38 contributors, 444 commits

Watch out for

  • Scraping can break. Platforms change their pages regularly, and channels that work today may stop working tomorrow. The README labels Twitter, Facebook and Instagram as 'experimental.'
  • Don't install the PyPI package. The README warns that a package named agent-reach on PyPI is not this project. Install only from the GitHub repo.
  • No official cryptocurrency. The README includes a warning that crypto projects using the Agent Reach name are unrelated scams. Don't connect a wallet or pay fees.
  • Some channels need logins. Bilibili subtitles, XiaoHongShu and LinkedIn require logging in. Login credentials are stored locally in ~/.agent-reach/.
