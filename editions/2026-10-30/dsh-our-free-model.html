How does it work?

Your problem

Using AI models through their official channels costs money - API fees add up, and free tiers run out.

When it kicks in

You install the plugin into DeepSeek Harness (a coding tool, like an AI-powered editor) and restart it.

You give it

Your prompts - the same questions and tasks you'd normally send to a paid AI model.

It does

It connects to free model gateways and routes your prompts through them.

  1. Checks which free model providers are available from your network
  2. Routes your prompt to the best available free gateway (OpenCode's Zen gateway, Kilo AI's public pool, or others)
  3. If one provider is overloaded, falls back to the next one in a chain
You get

AI model responses without an API bill.

  • Free model accessPrompts routed through free gateways to models like DeepSeek V4.1 Flash and Kimi K3
  • A local forwarding portA local connection point so other tools on your computer can use the free models too

What changes for me?

Without it

  • Using AI models costs money - credits, subscriptions, or pay-per-message fees that add up with heavy use
  • Free tiers from providers have strict limits and require sign-ups with email verification
  • Switching between free providers means managing multiple accounts and API keys

With it

  • Send prompts to frontier models without paying - the plugin handles provider routing and fallbacks
  • No sign-up needed for the basic free lane (some premium channels require a GitHub login)
  • A local connection point lets other tools on your machine use the same free models

Effort

  2. Clone this repo and run dsh plugin --profile web add /path/to/dsh-our-free-model, then restart DeepSeek Harness

Should I?

Great if you...

  • DeepSeek Harness users who want to try AI models without paying for API credits
  • Hobbyists experimenting with different AI models on personal projects

Skip it if...

  • You need reliable, guaranteed uptime - free gateways can throttle or disappear
  • You send sensitive data - the README warns that free providers may log prompts
  • You don't use DeepSeek Harness (this is a plugin for that specific tool)

Watch out for

  • Suspicious star growth. The repo has 52K stars but only 40 watchers - a ratio that is far outside the normal range. The stars may not reflect real adoption.
  • Free providers may log your prompts. The README says Kilo's free pool 'may log prompts and use them to improve services.' Don't send passwords, API keys, personal data or confidential material.
  • Free quotas can vanish. The upstream providers set the free limits and can change, throttle or remove them at any time. The plugin has no control over this.
  • Don't install from npm. The README warns that a package named dsh-our-free-model on npm is a third-party copy and differs from this repo.
