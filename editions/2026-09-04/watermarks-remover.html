● What makes it stand out

Three-layer removal pipeline

Layer A - deterministic Unicode cleanup (invisible characters, variation selectors, zero-width marks). Layer B - statistical rewrite hooks for text watermarks. Layer C - C2PA, EXIF, XMP, and container metadata stripping.

Multi-vendor coverage

Targets marks from Claude (Anthropic's seam watermark), Gemini (Google SynthID-Text), ChatGPT (OpenAI provenance surfaces), and open-weight models using Kirchenbauer-style marks.

20+ format support

Handles PNG, JPEG, SVG, PDF, DOCX, HTML, Markdown, FLAC, and more. Each format gets a targeted removal strategy - not a generic metadata wipe.

Detection-guided rewriting

Integrates vendor watermark detectors (SynthID scorer, Claude seam detector, MarkLLM) to evaluate variants iteratively until an attempt passes the evaluator.

Claude Code plugin

Started as a Claude Code skill and still ships as one. Run /remove-ai-marks inside Claude Code to clean outputs without leaving your workflow.

Privacy-first design

All processing runs locally. No files are uploaded to external servers. The tool is designed for cleaning content you own - not for circumventing attribution on others' work.

Single best feature

Honest about its own limits

The creator publicly states that Layer A (Unicode cleanup) and Layer C (metadata stripping) work reliably, but Layer B (statistical watermark removal) cannot be independently verified because Anthropic has not published its detector. The removal matrix in the repo documents exactly what works, what partially works, and what remains unproven. That transparency is rare in this space.

The invisible ink problem

The EU AI Act took effect August 1, 2026, requiring AI-generated content to be labeled. Days later, Anthropic switched on invisible text watermarks in Claude. If you use AI to draft content you then edit and own, those marks follow your work.

Before

Hidden marks in your writing. Every text produced by Claude carries an invisible statistical watermark baked into word choices. You cannot see it, but a detector can flag your edited document as "AI-generated" even after heavy revision.

Metadata you did not ask for. Images, PDFs, and documents produced by AI tools embed C2PA, EXIF, and XMP provenance metadata. Share a file and its origin story travels with it - whether you intended that or not.

Unicode steganography. Invisible Unicode characters - variation selectors, zero-width joiners, directional marks - get sprinkled into AI-generated text. Most text editors cannot display them, but they persist through copy-paste.

After

Clean text, your choice. Layer A strips invisible Unicode artifacts deterministically. No rewriting needed, no meaning changed - just the hidden characters removed.

Metadata under your control. Layer C removes C2PA signatures, EXIF tags, and XMP blocks from images, PDFs, and documents. You decide what provenance data ships with your files.

Statistical marks addressed. Layer B uses detection-guided iterative rewriting to reduce the signal that statistical watermark detectors look for. Results vary by vendor and model - the removal matrix documents the current state honestly.

Get clean

Clone the repo, install dependencies, configure your target vendors, and run the removal pipeline. Works standalone or as a Claude Code skill.

1

Clone the repository

# Clone watermarks-remover
git clone https://github.com/guillaumemeyer/watermarks-remover.git
cd watermarks-remover

The repo includes the CLI tool, the Claude Code skill, removal layers, and the vendor detection integrations.

2

Install dependencies

# Create a virtual environment
python -m venv .venv
source .venv/bin/activate

# Install the package
pip install -e .

Requires Python 3.10+. Optional extras for SynthID detection and image processing are available via pip install -e ".[synthid,images]".

3

Configure target layers

# Copy the example config
cp config.example.yaml config.yaml

# Enable the layers you need:
# layer_a: true   # Unicode cleanup (safe, deterministic)
# layer_b: false  # Statistical rewrite (experimental)
# layer_c: true   # Metadata stripping (reliable)

Layer A and Layer C are safe defaults. Layer B involves rewriting text via a second model and should be reviewed carefully before enabling.

4

Run the remover

# Clean a single file
watermarks-remover clean document.pdf

# Clean a directory of files
watermarks-remover clean ./output/ --recursive

# Or use as a Claude Code skill
# claude /remove-ai-marks

The CLI outputs a cleaned copy alongside the original. Use --in-place to overwrite. The Claude Code skill runs the same pipeline interactively.

Watch out for

  • Statistical removal is unverified. Layer B claims to reduce statistical watermark signals, but Anthropic has not published its detector. There is no independent way to confirm the text watermark is actually gone after processing.
  • Dual-use concerns are real. The same tool that helps a privacy-conscious user clean their personal notes also helps a content farm strip provenance before publishing AI-generated content. The ethical tension is inherent and unresolved.
  • Legal gray area. The EU AI Act requires AI-generated content to be labeled. Stripping those labels from content you did not create may violate the regulation. The tool's "content you own" framing is a license-level disclaimer, not legal advice.
  • Layer B rewrites your text. Statistical watermark removal works by rewriting text through a second model. This changes your words. The output may not say what you intended. Always review Layer B output carefully.
