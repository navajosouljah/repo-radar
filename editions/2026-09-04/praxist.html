● What makes it different

Parallel Research Peers

Multiple autonomous agents explore competing approaches simultaneously. Each peer runs its own experimental loop, tests hypotheses, investigates failures, and validates promising results independently.

Shared Research Graph

Every experiment - successful or failed - is logged to a durable research graph tracking findings, evidence strength, and lineage. Later experiments pull from the graph to reuse validated mechanisms.

Generation-to-generation synthesis

Unlike one-shot coding agents, PRAXIST carries evidence across generations. Each generation of experiments builds on cumulative findings, not just the best single candidate.

Task-owned evaluation

Every research objective carries its own evaluation criteria. PRAXIST does not rely on generic metrics - it validates solutions against the specific measurable goals you defined.

Negative knowledge tracking

Failed experiments are first-class citizens. The system records what did not work and why, preventing future peers from repeating dead-end approaches and accelerating convergence.

49 MLE-Bench gold medals

Achieved 49 gold-medal outcomes across 75 Kaggle competitions at approximately $3K in model cost - compared to 34 golds for Claude Code at $38K under the same conditions.

Single Best Feature

Cumulative experimental research, not one-shot task execution

The core insight is that real research is iterative and cumulative. General coding agents execute tasks. PRAXIST discovers the research approach itself. Multiple peers explore competing hypotheses in parallel, store every finding in a shared research graph, and synthesize across generations - so the 50th experiment knows everything the first 49 learned, including what failed and why.

The research loop problem

Real R&D requires long-horizon exploration, parallel hypothesis testing, and cumulative evidence. Single-shot coding agents were never designed for this.

Before

One-shot task execution. Coding agents run a single approach, return a result, and forget everything. If the first attempt fails, you start from scratch with a new prompt. No learning, no accumulation.

Failed experiments vanish. When an approach does not work, the evidence disappears. The next run has no idea what was already tried or why it failed. Repeated dead ends waste time and compute.

Serial exploration only. You test one hypothesis at a time, manually review results, decide the next direction, and write a new prompt. The human is the bottleneck in the research loop.

After

Cumulative multi-generation research. PRAXIST carries findings forward. Generation N+1 builds on everything generation N discovered - successes, failures, and partial results are all available.

Durable evidence graph. Every experiment, finding, and failure is stored with evidence strength and lineage. Later peers reuse validated mechanisms and avoid proven dead ends.

Parallel exploration. Multiple Research Peers test competing hypotheses simultaneously. The system synthesizes across branches, combining discoveries that no single peer would have found alone.

Get started

Install PRAXIST, configure your LLM provider, define a research objective, and let the system discover the approach.

1

Clone and install

# Clone PRAXIST
git clone https://github.com/sapientinc/PRAXIST.git
cd PRAXIST

# Install dependencies
pip install -e ".[all]"

Requires Python 3.10+. The [all] extra includes all supported LLM backends and evaluation frameworks.

2

Configure your LLM provider

# Set your API key (supports multiple providers)
export DEEPSEEK_API_KEY="your-key-here"

# Or use Anthropic, OpenAI, etc.
export ANTHROPIC_API_KEY="your-key-here"

PRAXIST's MLE-Bench results used DeepSeek V4 Pro. Any provider with function-calling support works. Model cost scales with the number of peers and generations.

3

Define a research objective

# Create a research configuration
praxist init my-research

# Edit the generated config
# Define: objective, constraints, success criteria,
# evaluation metrics, and compute budget
vim my-research/config.yaml

The config file specifies what success looks like - measurable criteria that PRAXIST uses to evaluate and compare experimental results across peers and generations.

4

Launch the research loop

# Start PRAXIST with your research config
praxist run my-research/config.yaml \
  --peers 4 \
  --generations 10 \
  --budget 50.00

# Monitor progress in real time
praxist status my-research

PRAXIST spawns parallel Research Peers that explore competing approaches. The --budget flag caps total LLM spend. Use praxist status to monitor the research graph as it grows.

Watch out for

  • One week old. Created August 27, 2026, and shipped as beta. Expect breaking changes, incomplete documentation, and evolving APIs. Production deployments should pin versions carefully.
  • LLM costs can escalate. Parallel peers across many generations consume significant API tokens. The --budget flag caps spend, but misconfigured runs with many peers and generations can burn through credits quickly. Monitor costs closely.
  • "Other" license. The license is not a standard OSI-approved license. Review the terms carefully before using PRAXIST in commercial research or integrating its outputs into proprietary systems.
  • MLE-Bench is one benchmark. The 49-gold result is impressive but narrow. MLE-Bench tests machine learning engineering on Kaggle-style problems. Performance on novel research domains, open-ended exploration, or non-ML tasks is unproven.
