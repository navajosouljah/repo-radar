How does it work?

Your problem

Every time you start a new session with your AI coding agent, it forgets everything - your preferences, your past decisions, the context you built up. You repeat yourself constantly.

You told Claude Code last week that you prefer Tailwind over CSS modules, but today it suggests CSS modules again because it has no memory of that conversation.

When it kicks in

claude-mem runs automatically at the start and end of every session, loading and saving memories.

Start a new Claude Code session and the agent automatically retrieves your stored preferences, decisions and project context - no manual recall needed.

You give it

Your conversations with the agent - it captures preferences, decisions and important context as you work.

When you say 'I prefer functional components over class components,' claude-mem stores that as a permanent preference.

It does

It stores memories in a local database and automatically retrieves the relevant ones at the start of each session.

  1. At the end of a session, 5 lifecycle hooks capture preferences, decisions and context and store them in a local SQLite database with Chroma for search
  2. At the start of the next session, it retrieves the memories most relevant to what you're working on
  3. Tools let you search, add or edit memories manually if you want to

The README demo: the agent remembers that your project uses a specific testing framework and applies that context without being told again.

You get

An AI agent that gets better the more you use it - because it remembers.

  • Persistent preferencesYour coding style, framework choices and project conventions, applied automatically in every session
  • Decision historyPast architectural decisions and their reasoning, so the agent doesn't suggest what you already rejected

What changes for me?

Without it

  • Every new session starts from zero. The agent doesn't know your preferences, your project's conventions, or what you decided last week.
  • You repeat the same context at the start of every session - framework choices, coding style, project structure.

With it

  • The agent remembers your preferences, decisions and project context across sessions - it gets better the more you use it.
  • No manual recall needed. Relevant memories load automatically when you start a new session.

Should I?

Great if you...

  • You use Claude Code daily and are tired of repeating your preferences, project conventions and past decisions at the start of every session
  • You want your AI agent to get better over time by learning from your conversations

Skip it if...

  • You prefer to control exactly what context the agent sees - claude-mem captures memories automatically, which may include things you'd rather forget
  • You already use a manual memory system (like CLAUDE.md files) that gives you full control over what the agent knows

Instead, you could look at

  • CLAUDE.md filesClaude Code's built-in memory files. You write the context by hand, so you control exactly what the agent knows - but nothing is captured automatically.
  • ObsidianA personal knowledge base you manage yourself. Not AI-agent memory, but a structured way to keep notes your agent can read.

Is it safe?

PASSED

Watch out for

  • CMEM cryptocurrency token. The creator endorses a CMEM token associated with the project. The open-source tool works without the token, but its existence is worth knowing.
  • Paid tier after 30 days. CMEM Pro costs $30/month after a 30-day free trial. The core open-source features work without it, but some advanced features are gated.
  • By Alex Newman (thedotmack). A solo developer project with 3,222 commits. The Apache-2.0 license means the code is open, but long-term maintenance depends on one person.
  • Automatic memory capture raises privacy questions. The tool captures preferences and decisions from your conversations and stores them locally. Review what it stores periodically.
