Ghidra

A free reverse engineering toolkit from the NSA that takes apart software so you can see how it works inside.

Open any compiled program and Ghidra turns the machine code back into readable logic - for example, load a suspicious file and see every function, string and call it makes.

How does it work?

Your problem

You have a compiled program - an app, a firmware file, a suspicious download - and you need to understand what it actually does. The source code is not available.

Your security team receives a suspicious executable. Without a reverse engineering tool, it is a black box.

When it kicks in

You open Ghidra's desktop application and import a binary file - an executable, a library, or a firmware image.

Drag a .exe or .so file into Ghidra's project window and it asks which processor architecture to use for analysis.

You give it

A compiled binary file. Ghidra supports over 30 processor architectures, from x86 and ARM to MIPS, PowerPC, and microcontrollers.

An Android native library (.so), a Windows executable (.exe), a macOS binary, or a raw firmware dump.

It does

Ghidra disassembles the binary into assembly instructions, then decompiles it into C-like code you can read and navigate.

  1. Analyzes the binary and maps out every function, string, data reference and call graph automatically
  2. Decompiles machine code into readable C-like pseudocode, with variable names and types it infers from the analysis
  3. Lets you rename variables, add comments, and navigate between the assembly view and the decompiled view side by side
  4. Supports team collaboration - multiple analysts can work on the same binary through a shared Ghidra Server

The CodeBrowser window shows assembly on the left, decompiled C on the right, and a function list for navigation.

You get

You can read and understand what a compiled program does, find vulnerabilities, and document your analysis.

  • Decompiled source codeMachine code turned into readable C-like functions with inferred variable names and types
  • Program mapsCall graphs, cross-references, and string tables that show how every piece of the program connects
  • Scripting and automationWrite Java or Python scripts to automate analysis tasks - for example, find every function that calls a dangerous API

What changes for me?

Without it

  • Reverse engineering a binary means either paying for IDA Pro (thousands of dollars per seat) or using limited free tools with no decompiler.
  • Analyzing a suspicious file takes specialized skills and expensive commercial software, so many teams skip deep analysis entirely.

With it

  • A professional-grade reverse engineering suite with a built-in decompiler, for free - the same class of tool that costs thousands in commercial licenses.
  • A team of analysts can work on the same binary together through Ghidra Server, with a full scripting system (Java and Python) for automation.

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Download the latest release (Ghidra 12.2) from the GitHub Releases page. You need JDK 25 installed first.
  2. Unzip and run the launcher (ghidraRun on Mac/Linux, ghidraRun.bat on Windows), create a new project, and import a compiled binary.
  3. Click Analyze when prompted. Ghidra maps the binary, then browse the CodeBrowser to see assembly and decompiled C side by side.

What it takes on your computer

Space on disk
The release ZIP is about 400-700 MB depending on the package. Installed size is roughly 750 MB to 1.4 GB with all processor modules.
Memory while it runs
Ghidra is a Java application. The default allocation is 768 MB to 2 GB of heap, depending on the binary size. Large binaries may need 4-8 GB.
Runs on
Mac, Windows, and Linux. Requires JDK 25 (Ghidra 12.2). No graphics card needed - it is a Java Swing desktop application.

Should I?

Great if you...

  • You need to understand what a compiled program does - malware analysis, vulnerability research, firmware inspection - and you do not have the source code
  • You want a professional reverse engineering suite without paying thousands for a commercial license like IDA Pro

Skip it if...

  • You are not a developer or security researcher - reverse engineering requires understanding assembly language and program structure
  • You need a quick, lightweight tool for simple binary inspection - Ghidra is a full IDE-sized application with a learning curve to match

Instead, you could look at

  • IDA ProThe industry standard for reverse engineering, with the most mature decompiler. Costs thousands per seat. Ghidra's closest commercial competitor.
  • Binary NinjaA modern commercial disassembler with a clean API and fast analysis. Cheaper than IDA Pro, with a free cloud version for small binaries.
  • Cutter (rizin)A free, open-source reverse engineering GUI built on the rizin framework. Lighter than Ghidra, but less powerful decompilation.

Watch out for

  • This is a developer tool. Reverse engineering requires understanding assembly language, calling conventions, and program structure. It is not something you install and point at a file for a plain-English answer.
  • NSA origin raises questions for some users. Ghidra was developed internally by the NSA before being open-sourced. The code is public and auditable under Apache-2.0, but some organizations have policies against NSA-originated software.
  • Large footprint. The download is 400-700 MB, the installed size can reach 1.4 GB, and analysis of large binaries needs several gigabytes of RAM. This is a full desktop application, not a lightweight tool.
  • JDK dependency. Ghidra 12.2 requires JDK 25 specifically. Keeping the right Java version installed and configured is an ongoing maintenance task.

Who's using it, and for what?

Ghidra has been public since March 2019 and is widely used in security research, government, and education. Individual adoption is rarely announced publicly because reverse engineering work is typically confidential.
