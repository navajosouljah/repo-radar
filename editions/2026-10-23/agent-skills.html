How does it work?

Your problem

Your AI coding agent jumps straight to writing code. It skips planning, rarely tests, and never reviews its own work - so you end up fixing things it should have caught.

You ask Claude Code to add a login page. It writes the code immediately, with no spec, no tests, and no check for security holes.

When it kicks in

You type a slash command in your AI coding agent - like /spec, /plan, /build, /test, /review, or /ship.

Type /spec in Claude Code and it interviews you about what you want before writing a single line of code.

You give it

A task description or a codebase. The skills guide the agent through each phase of the work.

'Add a dark mode toggle to the settings page' - the agent writes a spec, plans the steps, builds each one with tests, then reviews.

It does

The agent follows a structured workflow for each phase, with built-in quality gates that catch problems before they ship.

  1. Interviews you about requirements and writes a spec before any code (the /spec skill)
  2. Breaks the work into small tasks, builds each one incrementally, and writes tests for every piece
  3. Reviews its own code for bugs, security issues, and unnecessary complexity - and simplifies what it finds
  4. Commits each task separately with clear messages and runs final checks before marking it done

The README's /build auto example: the agent generates a plan, gets one approval, then implements all tasks - testing and committing each one individually.

You get

Your AI coding agent produces better, more reliable work - with specs, tests, reviews, and clean commits built into every task.

  • Structured specs and plansThe /spec command produces a requirements document; /plan breaks it into numbered tasks with dependencies
  • Tested, reviewed codeEach task gets its own tests, and /review catches bugs, security holes, and unnecessary complexity before shipping
  • Clean git historyEach task is committed separately with descriptive messages, not one giant commit at the end

What changes for me?

Without it

  • Your AI coding agent writes code immediately with no plan, no tests, and no self-review - you catch the mistakes after the fact.
  • Every agent stores instructions differently, so practices you set up in one tool do not transfer to another.

With it

  • The agent follows a full spec-plan-build-test-review-ship workflow automatically, catching problems before you see them.
  • One install puts the same 25 skills into Claude Code, Cursor, Codex, and 75+ other agents at once.

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Install all 25 skills into Claude Code: run /plugin marketplace add addyosmani/agent-skills, then /plugin install agent-skills@addy-agent-skills in your Claude Code terminal.
  2. Try the spec skill: type /spec and describe a feature you want to build. The agent will interview you about requirements before writing any code.
  3. Try the build skill: type /build auto with an approved spec. The agent plans, builds, tests, and commits each task on its own.

What it takes on your computer

Space on disk
No standalone install needed. Skills are Markdown files that install into your AI coding agent's configuration folder. The full pack is under 1 MB.
Memory while it runs
No data found. Skills are text files loaded by the agent on demand - they add no running processes.
Runs on
Any system where Claude Code, Cursor, Codex, or another supported agent runs. Mac, Windows, and Linux. Requires the skills tool (Node.js) or the agent's built-in plugin install.

Should I?

Great if you...

  • You use an AI coding agent and want it to follow a structured workflow - specs, plans, tests, reviews - instead of jumping straight to code
  • You work across multiple agents (Claude Code, Cursor, Codex) and want the same engineering practices in all of them

Skip it if...

  • You already have a well-tuned set of agent instructions and do not want another pack potentially conflicting with them
  • You prefer to give your agent open-ended freedom rather than structured workflows with quality gates

Instead, you could look at

  • anthropics/knowledge-work-pluginsAnthropic's own plugin pack for Claude Code. More focused on knowledge work than engineering workflows.
  • Manual CLAUDE.md instructionsWrite your own instructions directly in CLAUDE.md. More control, but you maintain them yourself and they only work in Claude Code.

Is it safe?

PASSED

The flagged hits were the repo's own security-hardening skill and a general Snyk study of malicious skills on a different marketplace.

Watch out for

  • Single-author dependency. The pack is maintained primarily by Addy Osmani with two listed collaborators. If he stops maintaining it, updates stop.
  • Skills run with your agent's permissions. These instructions become part of what your AI coding agent does. Review what they tell the agent to do, especially the automated commit and ship steps.
  • No independent benchmarks. The pack claims to improve agent reliability, but there are no published third-party measurements of the improvement. The approach is based on engineering experience, not controlled tests.
  • Name overlap with built-in commands. Some slash commands (like /review) share names with Claude Code's built-in commands. Use the namespaced form (/agent-skills:review) to avoid confusion.
