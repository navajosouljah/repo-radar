How does it work?

Your problem

Claude Code is powerful out of the box, but it does not know about your specific tools - your project manager, your design system, your database. Each new ability means writing instructions from scratch.

You want Claude Code to check your Sentry error dashboard before shipping, but it has no idea Sentry exists until someone writes the connection.

When it kicks in

You type a command in Claude Code and browse the plugin directory, or install one by name.

Type /plugin install sentry@claude-plugins-official and Claude Code gains the ability to read your Sentry errors.

You give it

A plugin name, or a keyword to search the directory. You can also browse what is available with the Discover tab.

/plugin opens the plugin menu; the Discover tab shows categories like productivity, data, and design.

It does

It downloads the plugin, installs it into Claude Code, and registers its commands, skills, and connections.

  1. Finds the plugin in Anthropic's curated directory or a community marketplace you have added
  2. Downloads and installs it - the plugin can include slash commands, agent definitions, skills, and server connections
  3. Claude Code loads the new abilities automatically the next time they are relevant to your task

The README shows the install flow: /plugin install {plugin-name}@claude-plugins-official and the plugin is ready.

You get

Claude Code has new abilities - each one vetted by Anthropic's review process before it appears in the directory.

  • New commands and abilitiesA data plugin adds /query so you can ask Claude Code to pull numbers from your database
  • A curated directoryEvery plugin goes through Anthropic's submission and security review before it is listed
  • Your own pluginsSubmit your own through the plugin directory submission form at clau.de/plugin-directory-submission

What changes for me?

Without it

  • Adding a new ability to Claude Code means writing custom instructions, server connections, and slash commands by hand - and hoping they work together.
  • There is no central, reviewed place to find ready-made add-ons. You copy configurations from blog posts and troubleshoot alone.

With it

  • One command installs a reviewed plugin that adds commands, skills, and connections to Claude Code - ready to use immediately.
  • A curated directory with a submission and security review process, so you are not installing unvetted code into your AI assistant.

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Open Claude Code and type /plugin to see the plugin menu, then browse the Discover tab for available plugins.
  2. Install one: type /plugin install {plugin-name}@claude-plugins-official - for example, a productivity or data plugin.
  3. Use it: the plugin's commands and abilities are now available. Type / to see any new slash commands it added.

What it takes on your computer

Space on disk
No standalone install needed. Plugins install inside Claude Code. Individual plugins are small - typically a few text files (JSON metadata, Markdown skills, and optional scripts).
Memory while it runs
No data found. Plugins run inside Claude Code's existing process.
Runs on
Wherever Claude Code runs: Mac, Windows, and Linux.
Source: claude-plugins-official README on GitHub

Paste this into Claude Code. It runs your safety scan first, then a 10-minute test.

/skillspector https://github.com/anthropics/claude-plugins-official

If that scan passes: run `/plugin` to browse the Discover tab, pick a plugin, install it, and try its new commands. 10 minutes max.

Should I?

Great if you...

  • You use Claude Code and want to add abilities - connecting to tools, new commands, specialized knowledge - without writing configuration from scratch
  • You want a reviewed source of add-ons rather than copying unvetted instructions from blog posts

Skip it if...

  • You do not use Claude Code - these plugins only work inside Claude Code
  • You prefer to write and maintain your own instructions rather than depend on third-party plugins that may change

Instead, you could look at

  • skills (Vercel)Cross-agent skill installer that works across 75+ agents, not just Claude Code. Broader reach, but no curated review process.
  • PlumA terminal browser that searches 11 plugin marketplaces at once, including this one. Useful if you want to compare options across registries.

Is it safe?

PASSED
  • Security advisories: 0GitHub's advisory list, checked Oct 23
  • Searches for CVEs, vulnerabilities, malware and scams2 results read, including the national CVE database: nothing found
  • Are the stars earned?44K stars, 49 contributors, 4.6K commits

Watch out for

  • Review is not verification. Anthropic's README warns that it 'does not control what MCP servers, files, or software a plugin includes' and 'cannot verify that plugins work as intended or won't change.' Review a plugin before installing it.
  • 1.1K open issues. The directory has a large backlog of open issues, which may reflect unreviewed submissions or unresolved reports.
  • Third-party plugins carry their own risk. External plugins in /external_plugins come from partners and the community. Each links to its own license and source.
