How does it work?

Your problem

Professional 3D design software costs hundreds per year, and the free options either lack parametric tools or run only on one platform.

When it kicks in

You download SolidCraft or open it in a browser and start modeling a part.

You give it

Your design idea - a bracket, an enclosure, a gear, a shelf mount - described in words, a sketch, or drawn with the tool's parametric editor.

It does

It gives you a full parametric modeling environment with constraints, sketches and a timeline.

  1. You create 2D sketches with lines, arcs, circles and constraints (like 'this edge stays parallel to that one')
  2. You turn sketches into 3D shapes with operations like extrude, revolve and fillet
  3. Every step is tracked in a timeline so you can go back and change a dimension and everything downstream updates
You get

A 3D model you can export, 3D-print, or hand to a manufacturer.

  • A parametric 3D modelA phone stand with adjustable dimensions that updates when you change the phone width
  • Export filesSTL files for 3D printing, STEP files for manufacturing
  • A shareable linkWhen using the browser version, a link anyone can open to view or remix your design

What changes for me?

Without it

  • Professional CAD costs $500+/year (SolidWorks, Fusion 360) or locks your files in the cloud
  • Free alternatives like FreeCAD have steep learning curves and no AI integration
  • Sharing a design means exporting files and emailing them

With it

  • A free, open-source parametric CAD that runs on desktop, in the browser, or from the command line
  • A plugin lets your AI agent create and modify 3D models for you
  • Designs live in standard formats you own - no vendor lock-in

How hard is it to try?

Effort

5 minutesAbout an hourNeeds a developer
  1. Open SolidCraft in your browser - no download needed, it runs in Chrome, Firefox or Safari.
  2. Or download the desktop app for Mac, Windows (also via winget install solidcraft), or Linux.
  3. Start with the built-in tutorial: sketch a rectangle, constrain its dimensions, extrude it into a box, and fillet the edges.

What it takes on your computer

Space on disk
The desktop app is roughly 50-100 MB. Source build needs Rust toolchain (~1 GB with dependencies).
Memory while it runs
Runs on modest hardware. The browser version works in any modern browser.
Runs on
Mac, Windows, Linux (desktop). Any modern browser (web version). MCP server for AI agents.

Should I?

Great if you...

  • Hobbyists and makers who want parametric CAD without paying for SolidWorks
  • Anyone who wants to describe a part to an AI agent and get a 3D model back
  • Teams who need to share designs in a browser without installing software

Skip it if...

  • You need production-grade CAD with assembly tools and simulation (use Fusion 360 or SolidWorks)
  • You already have a CAD tool you're productive in
  • You need NURBS surfaces for organic shapes (SolidCraft is focused on solid modeling)

Instead, you could look at

  • FreeCADThe established open-source parametric CAD - more mature but no browser version or AI integration
  • OpenSCADCode-based 3D modeling - write scripts instead of drawing, good for programmers

Is it safe?

PASSED
  • Security advisories: 0GitHub's advisory list, checked Oct 23
  • Searches for CVEs, vulnerabilities, malware and scams7 results read, including the national CVE database: nothing found
  • Are the stars earned?9.5K stars, 138 contributors, 1.9K commits. findarepo: looks organic

Watch out for

  • 16 days old. The feature set is growing fast (1,937 commits, v0.15.0) but expect rough edges - slow fillets and booleans are known issues.
  • Unsigned installers. The Windows and Mac desktop installers are not code-signed, so your OS will warn you when you install them.
  • Longevity uncertain. HN commenters worry about long-term maintenance. CAD files need to stay openable for years, and a 16-day-old project has not proven that yet.
  • Large STEP imports may fail. A Hackaday commenter could not load a large 3D printer STEP file. Complex imported models may hit limits.

SolidCraft is 16 days old. Hackaday commenters report modifying designs and exporting to PrusaSlicer, but documented production use is still early.
